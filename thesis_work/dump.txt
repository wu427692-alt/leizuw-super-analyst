   | 一、选题意义 / 1．选题背景 / 在线评论是消费者网购时了解商品质量和使用体验的重要来源。随着电商平台的发展，热门商品的评论常常多达数千条，消费者想从中找到自己需要的信息，往往要花费较多的时间和精力。近年来，随着生成式人工智能技术快速发展，许多平台开始利用AI对用户评论进行归纳，生成AI评论摘要。2023年8月，亚马逊在美国移动端上线了基于生成式AI的“评论亮点”功能，用一段简短的文字概括多条评论的主要观点，并在下方提供可点击的商品属性标签（Amazon，2023）。Wang和Wang（2025）利用亚马逊平台数据研究发现，引入AI评论摘要后，相关商品的购买行为指标有所改善。AI评论摘要正逐渐成为消费者获取评论信息的重要途径。 / 此外，不同平台的AI评论摘要在内容组织上差别较大。苹果App Store用一段连续的文字概括用户评价；Naver Shopping按满意度、穿着舒适度、价格等属性分条给出摘要；美团到店把评价要点分成“优点”和“缺点”两栏；Tripadvisor先用一段话给出总体评价，再按位置、房间、服务等属性列出细项。 /   / 图1  部分平台AI评论摘要的组织方式 / 从图1可以看出，各平台的做法主要在两个地方有差别：第一是摘要内容按什么分组。一条评论通常包含两部分信息：评价的是商品的哪个属性，以及。Naver Shopping按属性分组，美团按效价分组，App Store则不分组，把所有评价写在一段话里。第二是分组内容前面有没有一段总体评价。Tripadvisor在各属性的细项之前先用一段话概括消费者对酒店的整体看法，；Naver Shopping和美团则直接列出分组内容缺少独立总览。 / 同样的评价内容，分组方式不同，消费者查找某个属性的评价、判断商品整体好坏的难易程度就不同；有没有独立总览，也会影响消费者形成整体判断所要花的工夫。这些差别可能影响消费者是否觉得摘要有用，以及是否愿意依据摘要作出判断。 / 因此，本文将从“分组依据”和“有无独立总览”两个方面研究AI评论摘要的呈现模式。实验中把分组依据（按属性、按优缺点）和独立总览（有、无）两两组合，形成四种摘要，并以不分组的整体概括式作为补充对照组。本文以信息采纳模型为理论基础，检验前述两个方面对消费者采纳意愿的影响，以及感知有用性在其中的中介作用。 / 2． 选题意义 / 2.1 理论意义 / 首先，现有AI评论摘要研究多关注摘要的生成来源（AI或人工）以及平台引入摘要的效果，对摘要内部的信息组织方式讨论较少，已有的比较也只区分了列表体和叙事体两类。本文把摘要的组织方式拆成分组依据和有无独立总览两个方面，分别检验它们的作用以及二者的交互作用，可以更具体地说明摘要的哪些设计会影响消费者，丰富AI评论摘要呈现方式的研究。 / 其次，已有信息采纳模型研究的对象大多是单条评论或社区中的帖子。本文把该模型用于AI评论摘要情境，以感知有用性为中介变量，检验呈现模式影响采纳意愿的路径，拓展了信息采纳模型的应用范围。 / 2.2 实践意义 / 平台在设计AI评论摘要时，需要决定两件事：摘要内容按属性分组还是按优缺点分组，以及是否在分组内容前加一段总体评价。本文的研究可以从以下几个方面为平台提供参考。 / 第一，帮助平台选择摘要的基本结构。很多商品页面已经有属性标签或分项评分，按属性组织摘要可以和这些模块对应起来；按优缺点组织则更接近消费者权衡利弊的习惯。比较两种分组方式下消费者的感知有用性和采纳意愿，可以为平台设计摘要模板提供依据。 / 第二，帮助平台判断是否需要独立总览。总览会增加摘要的篇幅，在手机页面上要占用更多空间。检验总览的作用，可以帮助平台判断这部分篇幅是否值得，以及在页面空间有限时能否省去。 / 第三，帮助平台搭配两种设计。如果总览的作用随分组方式而变化，平台可以根据已经采用的分组方式决定是否加总览。此外，实验中设置了不分组的整体概括式作为对照，结果可以说明把摘要整理成分条结构对消费者有多大帮助，为仍采用连续段落的平台改版提供参考。 | 一、选题意义 / 1．选题背景 / 首先，现有AI评论摘要研究多关注摘要的生成来源（AI或人工）以及平台引入摘要的效果，对摘要内部的信息组织方式讨论较少，已有的比较也只区分了列表体和叙事体两类。本文把摘要的组织方式拆成分组依据和有无独立总览两个方面，分别检验它们的作用以及二者的交互作用，可以更具体地说明摘要的哪些设计会影响消费者，丰富AI评论摘要呈现方式的研究。 / 其次，已有信息采纳模型研究的对象大多是单条评论或社区中的帖子。本文把该模型用于AI评论摘要情境，以感知有用性为中介变量，检验呈现模式影响采纳意愿的路径，拓展了信息采纳模型的应用范围。 / 2.2 实践意义 / 平台在设计AI评论摘要时，需要决定两件事：摘要内容按属性分组还是按优缺点分组，以及是否在分组内容前加一段总体评价。本文的研究可以从以下几个方面为平台提供参考。 / 第一，帮助平台选择摘要的基本结构。很多商品页面已经有属性标签或分项评分，按属性组织摘要可以和这些模块对应起来；按优缺点组织则更接近消费者权衡利弊的习惯。比较两种分组方式下消费者的感知有用性和采纳意愿，可以为平台设计摘要模板提供依据。 / 第二，帮助平台判断是否需要独立总览。总览会增加摘要的篇幅，在手机页面上要占用更多空间。检验总览的作用，可以帮助平台判断这部分篇幅是否值得，以及在页面空间有限时能否省去。 / 第三，帮助平台搭配两种设计。如果总览的作用随分组方式而变化，平台可以根据已经采用的分组方式决定是否加总览。此外，实验中设置了不分组的整体概括式作为对照，结果可以说明把摘要整理成分条结构对消费者有多大帮助，为仍采用连续段落的平台改版提供参考。
   | 二、国内外研究现状概述 / 本文关心的是消费者怎样看待和使用AI评论摘要。按照“信息本身—信息的呈现—信息的采纳”的顺序，本部分先梳理在线评论的研究，再梳理AI评论摘要的研究，然后介绍信息采纳模型，并分别梳理模型中的感知有用性和采纳意愿，最后进行述评。 / 1 在线评论 / 1.1 在线评论的定义 / 在线评论源于口碑传播。传统口碑是消费者之间面对面的、非商业性的信息交流，互联网普及后，这种交流逐渐转移到线上。Hennig-Thurau等（2004）将网络口碑定义为潜在、现有或过去的消费者通过互联网发布的、关于产品或企业的任何正面或负面陈述，这些陈述可以被大量的个人和机构看到。在线评论是网络口碑中最常见、也最受研究关注的一种形式。Chen和Xie（2008）认为，在线消费者评论是用户根据个人使用经历发布的产品信息，可以看作营销沟通组合中的一种新要素；Mudambi和Schuff（2010）将在线评论定义为消费者在企业网站或第三方网站上发布的产品评价。 / 以上三种界定都包含三层含义：评论由消费者发布，内容来自其购买和使用经历，并在网络平台上公开展示。与传统口碑相比，在线评论的传播范围更广，一条评论可以被所有浏览商品页面的人看到；评论可以长期保存，消费者能够同时查看大量历史评论；发布者大多是陌生人，消费者无法像判断熟人意见那样判断其可靠性。相较于社交媒体上的分享内容，电商平台与点评网站的在线评论多围绕具体商品展开，通常由评分和文字组合而成，并由平台统一展示。由于评论数量庞大且来源分散，平台需要对这些评论进行进一步整理与呈现，AI摘要便是其中形式之一。 / 1.2 在线评论的维度 / 在线评论包含的信息较多，学者们一般把它拆成若干维度分别测量。Babić Rosario等（2016）对96项研究的1532个效应量进行元分析时，把口碑指标归纳为数量、效价、数量与效价的组合以及离散度四类。更早的Floyd等（2014）对26项实证研究进行元分析时，以评论效价和评论数量作为两个基本指标。以上种种指标均可归类为反映评论所包含的信息内容。 / 此外，信息质量研究将信息的表达方式视为信息质量的一个维度。Wang和Strong（1996）把信息质量分为内在、情境、表达和可获得性四类，其中表达质量既包括格式上的简洁和一致，也包括含义上的可解释和易理解，可获得性质量则指信息是否容易获取。 / 据此，本文把在线评论的维度分为信息维度和呈现维度两类。信息维度包括评论数量、评论效价、评论离散度、评论内容和评论者特征五个方面，其中前三个描述一组评论的整体情况，后两个描述单条评论的特点；呈现维度指评论向消费者展示的形式，也分为若干方面。 / 评论数量指某一商品获得的评论条数，通常用评论总数或一段时间内新增的评论数衡量，反映商品受关注的程度。评论效价指评论的正负倾向，常用平均评分、好评率或正负评论的比例衡量。Liu（2006）研究电影口碑时，分别用评论条数和正负评论的比例衡量数量和效价；Chevalier和Mayzlin（2006）则用平均星级以及一星、五星评论所占的比例衡量效价。Babić Rosario等（2016）指出，有些研究用“五星评论的条数”衡量效价，这类指标实际上同时包含了数量信息，应当单独作为“数量与效价的组合”来处理，否则会影响不同研究结论之间的比较。 / 评论离散度指不同消费者的评价之间的分歧程度，一般用评分的方差或标准差衡量。两件商品的评论数量和平均评分可能相同，但一件商品的评价比较一致，另一件商品好评和差评都很多，消费者从中得到的信息并不一样。 / 评论内容指评论文本本身的特征，是研究最多的维度，常用指标包括评论长度或深度、评论质量、可读性和情感倾向等。Mudambi和Schuff（2010）用评论字数衡量评论深度；Park等（2007）在实验中按论据是否客观、具体、有理由支撑来区分高质量评论和低质量评论；Korfiatis等（2012）用可读性指数衡量评论是否容易读懂；郝媛媛等（2010）通过文本挖掘提取评论的情感倾向和主客观表达等特征。 / 评论者特征指发布评论的消费者本身的信息，如评论者等级、历史评论数量、是否公开身份以及在平台上获得的认可等。这类信息一般显示在评论旁边，消费者会据此判断评论者是否可靠。 / 呈现维度与信息维度相互独立，同样的评论内容可以有不同的展示形式。在线评论研究中已有学者把呈现形式作为评论的一个特征，Xu等（2015）就把文字、图文和视频称为评论的不同呈现格式。呈现形式有的由评论者决定，如是否上传图片；有的由平台决定，如评分汇总、评论排序和评论摘要。由于本文研究的AI评论摘要属于后者，下一节对呈现维度单独展开梳理。 / 1.3 在线评论的呈现形式 / 呈现形式是呈现维度在平台上的具体表现。同样的评论内容，展示方式不同，消费者获取的信息和阅读顺序也会不同。根据平台实践和已有研究，本文从单条评论和多条评论两个层面梳理在线评论的呈现形式：前者关注单条评论的呈现载体和结构，后者关注平台对大量评论的汇总、排序和归纳方式。 / 单条评论的呈现首先体现在载体上。在线评论经历了从纯文字到图文结合、再到视频的变化，目前淘宝、京东等平台都允许消费者在评论中上传图片和视频。Xu等（2015）通过实验比较了文字评论、图文评论和视频评论三种呈现方式，发现消费者对视频评论的可信度和说服力评价更高，并且这种差异会随产品类型而变化。 / 单条评论的呈现还体现在结构上。多数平台的评论是消费者自由撰写的一段文字，也有平台要求按固定栏目填写，如分别填写优点和缺点，或对外观、性能等属性分别打分，这类评论称为结构化评论。刘亚男等（2022）通过组间实验比较了结构化评论和非结构化评论，发现对于体验型产品，结构化评论能提高评论深度和消费者的感知诊断性，对于搜索型产品则作用不明显。此外，国内电商平台普遍提供追加评论功能，消费者可以在初次评论一段时间后补充使用体验，使一条评论在时间上分成前后两部分。王长征等（2015）研究了消费者对追加评论有用性的感知，石文华等（2016）对初次评论和追加评论进行了比较，追加评论已经成为国内在线评论研究的一个专门方向。 / 多条评论层面的呈现形式主要有三类。一是评分汇总，平台通常在评论区顶部展示平均星级、评论总数和各星级的分布，消费者往往先看汇总评分，再看具体评论。Qiu等（2012）通过实验发现，当汇总评分与单条评论的倾向相矛盾时，消费者会降低对这条评论的可信度和诊断性判断，而且这种影响对正面评论更明显。这说明消费者会把汇总信息和单条评论放在一起理解。 / 二是评论的排序与组合。平台一般提供按时间、按有用性投票或按评分筛选等排序方式，消费者实际看到的只是排在前面的一部分评论。Purnawirawan等（2012）把消费者看到的多条评论作为一个“评论集合”来研究，发现集合中正负评论的比例和排列顺序都会影响消费者对整组评论的评价：正面或负面占多数的集合比正负各半的集合评价更高，把负面评论放在中间、首尾放正面评论的排列方式也能提高评价。 / 三是对评论内容进行归纳。一些平台从评论中提取高频词，生成“质量很好”“尺码偏大”等评论标签，并标注提及次数。刘景方等（2016）研究了用户评论标签摘要系统的有效性，这类系统按标签对评论进行归纳，帮助用户较快了解评论的主要观点。标签保留了评论中的具体属性信息，形式上是关键词的罗列。近年来出现的AI评论摘要更进一步，平台直接把多条评论的观点写成一段文字或若干条目，消费者不需要阅读原文就能了解评论的大致情况。AI评论摘要的相关研究放在第2节中梳理。 / 总体而言，在线评论呈现形式的研究对象已从单条评论扩展到由多条评论组成的评论集合，平台对评论的加工程度也不断提高，从展示原文、汇总评分、提取标签发展到直接生成摘要。加工程度越高，消费者获取的信息越依赖平台的组织方式。 / 在线评论呈现形式的研究覆盖了载体、结构、评分汇总、排序和标签等多种形式，研究对象多为单条评论或原始评论列表，对平台加工后形成的摘要关注较少。从信息维度看，AI评论摘要实际上是把一组评论的效价、离散度和评论内容中涉及的商品属性压缩成一份概括。从呈现维度看，结构化评论按优缺点或按属性组织单条评论，与AI评论摘要中按优缺点分组、按属性分项的做法组织逻辑相近，区别在于后者组织的是多条评论归纳后的内容。 / 据此，本文研究的在线评论限定为电商平台上的商品评论，研究对象是由多条评论归纳而成的AI评论摘要。在信息维度上，实验中各组商品的评论数量、平均评分以及摘要所依据的评价内容保持一致；在呈现维度上，本文研究的是AI评论摘要内部的信息组织方式。 / 2． AI评论摘要 / 本节先梳理AI评论摘要的定义和发展，再梳理消费者对AI评论摘要的反应，最后梳理摘要呈现方式的研究和平台做法，并由此引出本文研究的两个方面。 / 2.1 AI评论摘要的定义与发展 / “评论摘要”的概念最早来自计算机领域的观点摘要研究。Hu和Liu（2004）把评论摘要界定为一种基于商品特征的摘要：先找出消费者在评论中评价过的商品特征，再判断每个特征上的评价是正面还是负面，最后按特征汇总。Kim等（2011）在综述中采用了更宽的界定，把对大量观点生成简洁、易于理解的摘要的研究都归入观点摘要，并指出摘要可以是汇总后的情感评分，也可以是按属性或主题分解的结构化摘要，或是一段文字摘要。这一领域的定义着眼于摘要任务和输出形式。 / 围绕这一任务，摘要技术经历了几个阶段，摘要的输出形式也随之变化。Hu和Liu（2004）的摘要按商品特征逐项列出正面和负面评价的数量及例句；Liu等（2005）开发的Opinion Observer系统把不同商品在各属性上的优缺点做成可视化比较。之后的研究转向生成连贯的摘要文本，Ganesan等（2010）提出的Opinosis方法利用评论中反复出现的表达生成简短概括；Chu和Liu（2019）提出的MeanSum模型在没有人工摘要作为训练样本的情况下，也能生成多条评论的综合摘要。 / 大语言模型得到应用后，研究重点转向摘要是否忠实于原始评论。Hosking等（2024）先检索有代表性的评论片段，再由大模型据此生成摘要，使摘要内容能追溯到原文；Siledar等（2024）建立了观点摘要的评价数据集，从忠实性、属性覆盖和情感一致性等方面评价摘要质量。时至今日，按属性列出、按正负对比和连续文本这几种输出形式的呈现，在今天平台上的AI评论摘要中都能看到。 / 生成式AI进入电商平台以后，营销和信息管理领域开始把AI评论摘要作为一种新的平台信息来研究，界定的角度也随之变化。Wang和Wang（2025）以亚马逊2023年上线的功能为对象，将其描述为平台利用人工智能为消费者评论生成简洁摘要，并在过滤虚假或无用评论后置于评论区顶部，作用是从大量评论中提取关键信息。Jia、Zhao和Zhang（2026）认为AI评论摘要是生成式技术分析大量消费者评论后浓缩而成的简洁段落或要点，并把它看作在线评论的“代理”。Jia、Chi和Chi（2025）按生成来源把评论摘要分为AI生成和人工生成两类，说明“AI”一词限定的是摘要的生成主体。国内研究多使用“人工智能生成评论总结”或“AI评论总结”等说法。张鹏和刘春慧（2026）认为，人工智能生成评论总结把分散、碎片化的个体评论转化为聚合性结论，它与个体评论的本质区别在于算法对信息的筛选、重组与建构，具体包括三个方面：识别评论的效价，把模糊的情感表达转为正面、中性或负面的明确分类；抽取评论涉及的维度，如质量、物流和服务，并把分散的内容归类整合；按一定规则对效价信息和维度信息进行二次编排，形成有逻辑的总结框架。 / 比较上述界定，各研究在三点上基本一致：摘要的对象是同一商品或服务的多条评论，生成者是平台的算法，产出是比原始评论简短得多的概括内容。不同之处在于，计算机领域从任务和输出形式出发，营销和信息管理领域从来源和功能出发，多数默认摘要由生成式AI产生。Kim等（2011）和Jia、Zhao和Zhang（2026）提到摘要可以是评分、段落或要点等不同形式，张鹏和刘春慧（2026）把“二次编排”列为摘要的特征之一。 / 结合上述研究和平台实践，本文统一使用“AI评论摘要”一词，将其定义为平台利用人工智能技术，对某一商品或服务的多条用户评论进行归纳后形成、并展示给消费者的摘要内容，主要包括评论中的共同观点、涉及的商品属性和评论效价。与在线评论相比，AI评论摘要由平台生成，内容是对多条评论的整合。 / 2.2 消费者对AI评论摘要的反应 / 在消费者对AI评论摘要的反应方面，不少研究从摘要来源入手。Jia、Chi和Chi（2025）通过三项酒店预订情境实验发现，人工摘要在部分条件下更容易获得消费者信任，但在负面评价条件下，AI摘要和人工摘要带来的预订意愿没有显著差异。Chai等（2026）把措辞也考虑进来，发现当摘要用“多数”等文字形式表达概率时，消费者对AI摘要的反应反而比对人工摘要更积极，感知客观性和信任在其中起中介作用。Jia、Zhao和Zhang（2026）则不比较来源，而是调查了713名消费者对AI摘要本身的感知，发现透明性、可理解性和便利性会影响消费者对摘要可信度的判断。 / 另有研究利用平台数据考察摘要上线后的实际效果。Wang和Wang（2025）用亚马逊商品面板数据和双重差分方法，发现引入AI评论摘要后商品的购买行为指标有所改善；张鹏和古新成（2026）以酒店平台为对象，发现AI评论总结上线后，用户评论数量的增速下降了。前者考察的是消费者的购买行为，后者考察的是评论撰写行为。 / 总的来看，计算机领域的研究主要关注摘要的生成方法及其准确性；营销和信息管理领域的研究主要关注消费者对AI摘要的信任，以及平台引入摘要后消费者购买和评论行为的变化，对摘要内部怎样组织信息关注较少。 / 2.3 AI评论摘要的呈现模式 / 学术研究中对AI评论摘要呈现方式的讨论还不多。张鹏和刘春慧（2026）按信息组织逻辑把摘要的呈现结构分为列表体和叙事体两类：列表体用相互独立的条目逐项陈列商品属性和对应评价，如“优势：续航时间较长，且性价比很高；劣势：有用户反馈机身偏重”；叙事体则借助属性之间的关联，用连贯的段落叙述评价。他们通过眼动实验比较了两种呈现结构以及正面在前和负面在前两种效价顺序，发现呈现结构、效价顺序和产品类型会共同影响消费者对正面内容的视觉注意，并进一步影响购买意愿。 / 从平台实践看，AI评论摘要的组织方式主要有四种：App Store用一段连续文字概括评价；Naver Shopping按商品属性分条列出；美团按优点和缺点分栏；Tripadvisor先用一段话给出总体评价，再按属性列出细项。比较这四种做法，可以看到它们在两个方面不同。第一个方面是分组依据，即摘要内容按什么分组。评论信息由商品属性和评论效价两种成分构成，Hu和Liu（2004）的评论摘要就是按商品属性汇总正负评价，优缺点分栏或按属性打分。摘要可以按属性分组，可以按效价分组，也可以不分组。第二个方面是有无独立总览，即分组内容之前是否另有一段总体评价。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。 / 用这两个方面可以描述上述四种做法：App Store不分组，整段文字本身就是对评价的总体概括，本文称为整体概括式；Naver Shopping按属性分组、没有独立总览，称为属性分项式；美团按效价分组、没有独立总览，称为优缺点分组式；Tripadvisor有独立总览，后面的细项按属性分组，称为总分结合式。总分结合式后面的细项也可以按效价分组，本文据此把它分为属性型和优缺点型两种。与张鹏和刘春慧（2026）的划分相比，他们的叙事体对应本文的整体概括式，列表体在本文中按分组依据分成属性分项式和优缺点分组式，总分结合式是本文增加的一类。 / 本文从分组依据和有无独立总览两个方面研究呈现模式，因为这两个方面决定了消费者打开摘要后先看到什么、按什么顺序找信息，也是各平台做法差别最大的地方。实验把两个方面交叉：分组依据取按属性和按优缺点两个水平，独立总览取有和无两个水平，得到属性分项式、优缺点分组式以及属性型和优缺点型两种总分结合式，共四组。整体概括式不分组作为补充对照组，用来比较分条组织和连续段落的差别。 / 3． 信息采纳模型 / 本文以信息采纳模型为理论基础。本节介绍模型的提出和后续扩展，并说明本文怎样使用这一模型。 / 3.1 模型的提出 / 信息采纳模型由Sussman和Siegal（2003）提出，用来解释个体在接收到信息后为什么会采纳这些信息。该模型结合了技术接受模型（Davis，1989）和精细加工可能性模型（Petty和Cacioppo，1986）。精细加工可能性模型认为，个体处理信息有中心路径和边缘路径两种方式，前者主要依据信息内容本身进行判断，后者主要依据信息来源等外部线索进行判断。信息采纳模型据此把论据质量和来源可信度作为前因变量，分别对应中心路径和边缘路径；同时借鉴技术接受模型中感知有用性影响使用意向的思路，把信息有用性作为中介变量，把信息采纳作为结果变量。Sussman和Siegal（2003）以企业员工收到的建议邮件为对象进行检验，发现论据质量和来源可信度会通过信息有用性影响员工对建议的采纳，员工的专业知识和涉入程度会调节这一过程。 / 3.2 模型的扩展与应用 / 此后，学者们在不同情境中对该模型进行了检验和扩展。Bhattacherjee和Sanford（2006）把精细加工可能性模型用于信息技术接受研究，用论据质量和来源可信度解释用户的感知有用性和态度，并发现用户的专业知识和工作相关性会调节这两条路径的作用。Zhang和Watts（2008）以两个在线社区为对象，发现论据质量和来源可信度都会影响成员对社区信息的采纳，当新信息与已有认知不一致或成员带着明确目的搜索时，成员对来源可信度的依赖会减弱。Cheung等（2008）把模型用于在线消费者社区，发现论据质量中的相关性和全面性对信息有用性的影响较大，而来源可信度的影响不显著。Erkan和Evans（2016）在社交媒体情境中提出扩展的信息采纳模型，加入了信息需求和对信息的态度两个变量，并把购买意愿作为信息采纳之后的结果。 / 从已有研究看，信息采纳模型已经从组织内部的邮件沟通扩展到在线社区、在线评论和社交媒体等情境，“信息有用性影响信息采纳”这一核心路径得到了反复验证。这些研究的前因变量主要是论据质量、来源可信度等内容与来源特征，信息的呈现形式很少被考虑。因此，本文以信息采纳模型为理论基础，把AI评论摘要的呈现模式作为影响消费者处理信息的前因，保留“感知有用性—采纳意愿”这一核心路径。 / 4． 感知有用性 / 4.1 感知有用性的定义 / 感知有用性最早来自技术接受模型。Davis（1989）将其定义为个体认为使用某一特定系统能够提高其工作绩效的程度。Sussman和Siegal（2003）把这一概念用到信息采纳研究中，提出了信息有用性，指个体认为使用某条信息能够帮助自己更好地完成任务的程度。在在线评论研究中，学者们常用“评论有用性”这一概念，Mudambi和Schuff（2010）将有用的评论定义为能够帮助消费者完成购买决策的评论。三个概念的适用对象依次为信息系统、一般信息和在线评论，核心含义一致，均指个体对某一对象能否帮助自己完成任务的判断。本文的研究对象为AI评论摘要，统一使用“感知有用性”这一表述，文中引用的信息有用性和评论有用性研究均按这一含义理解。 / 4.2 感知有用性的测量 / 已有研究测量有用性主要有两种方式。第一种是利用平台上的“有帮助”投票数或投票比例，如Mudambi和Schuff（2010）、Korfiatis等（2012）的研究，这类数据反映的是其他用户对单条评论的评价。第二种是用问卷测量消费者自己感知到的有用程度。Davis（1989）开发的感知有用性量表包括提高工作效率、提高工作绩效和更容易完成工作等题项；Cheung等（2008）结合在线评论情境，从“有价值的”“有信息量的”“有帮助的”三个方面测量信息有用性。多数研究把感知有用性作为单维变量处理。 / 4.3 感知有用性的影响因素 / 在有用性的影响因素中，研究最多的是评论内容本身。Mudambi和Schuff（2010）发现评论深度和评分极端程度会影响评论有用性，且评论深度对搜索型产品的作用更强。Korfiatis等（2012）发现，可读性对“有帮助”投票比例的影响比评论长度更大。郝媛媛等（2010）用国内影评数据得出的结论是，积极的情感倾向、较高的正负情感混杂度和较长的平均句长都会提高评论有用性。Cheung等（2008）则从论据质量的角度，发现相关性和全面性的影响最大。 / 也有研究关注信息来源和评论者特征的作用。Sussman和Siegal（2003）发现来源可信度会影响信息有用性；Pan和Zhang（2011）发现评论者在文字中表现出的创新性与评论有用性呈倒U型关系；Ghose和Ipeirotis（2011）把文本特征和评论者信息放在一起分析，发现主观性、可读性、拼写错误和评论者的历史信息都有影响；殷国鹏（2012）基于豆瓣网数据，发现评论与平均星级的偏差、评论者的社会特征也会起作用。 / 从呈现方式解释有用性的研究相对较少。刘亚男等（2022）发现，对于体验型产品，结构化呈现的评论能提高感知诊断性和感知有用性；Jia、Zhao和Zhang（2026）发现，AI摘要的可理解性和便利性会提高消费者对摘要的信任，并提高其感知帮助程度。 /  /  / 5 采纳意愿 / 5.1 采纳意愿的定义与测量 / 信息采纳指个体有目的地使用信息的过程（Sussman和Siegal，2003）。在在线评论情境中，Cheung等（2008）把信息采纳理解为消费者接受评论中的观点，并据此作出购买相关的决策。Erkan和Evans（2016）进一步区分了信息采纳和购买意愿，认为消费者先采纳信息，再形成购买意愿。在测量上，部分研究测量的是消费者已经发生的采纳行为，如Cheung等（2008）的题项询问消费者是否同意评论观点、是否按照评论建议采取过行动；也有研究测量消费者在当前情境下的采纳意愿，如刘亚男等（2022）测量的评论接受意愿，以及Jia、Zhao和Zhang（2026）测量的摘要采纳意愿。 / 5.2 采纳意愿的影响因素 / 信息有用性是影响信息采纳最直接的因素。Sussman和Siegal（2003）发现信息有用性在论据质量、来源可信度与信息采纳之间起中介作用；Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中发现，信息有用性会正向影响信息采纳；Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，摘要可信度会通过感知帮助程度影响消费者的采纳意愿。除有用性外，Filieri和McLeay（2014）发现信息的准确性、增值性、相关性、及时性以及产品排名都会影响游客对评论信息的采纳；Filieri（2015）发现消费者主要根据信息质量判断评论能否帮助自己识别商品的特点，即信息诊断性，而诊断性会进一步影响信息采纳。 /  /  / 6． 文献述评 / 综上所述，在线评论、信息采纳和感知有用性的研究基础比较扎实，概念、维度和量表都可以借鉴。评论的载体、结构、汇总评分和排列方式对消费者判断的影响，已在原始评论情境中得到较多检验，AI摘要情境中的相关研究还很少。AI评论摘要研究主要比较摘要的来源和平台引入摘要的效果，对呈现方式只比较过列表体和叙事体，摘要的分组依据和独立总览各自起什么作用还缺少检验。感知有用性和采纳意愿的研究也很少以整份AI摘要为对象。 / 基于此，本文以信息采纳模型为理论基础，以AI评论摘要的分组依据和有无独立总览为自变量，感知有用性为中介变量，消费者采纳意愿为因变量，通过2×2组间实验检验两个自变量的主效应和交互作用，以及感知有用性的中介作用，并以整体概括式作为补充对照组。 / 参考文献 / [1] 郝媛媛, 叶强, 李一军. 基于影评数据的在线评论有用性影响因素研究[J]. 管理科学学报, 2010, 13(8): DOI: 10.17705/1jais.00149. | 二、国内外研究现状概述 / 本文关心的是消费者怎样看待和使用AI评论摘要。按照“信息本身—信息的呈现—信息的采纳”的顺序，本部分先梳理在线评论的研究，再梳理AI评论摘要的研究，然后介绍信息采纳模型，并分别梳理模型中的感知有用性和采纳意愿，最后进行述评。 / 1 在线评论 / 1.1 在线评论的定义 / 在线评论源于口碑传播。传统口碑是消费者之间面对面的、非商业性的信息交流，互联网普及后，这种交流逐渐转移到线上。Hennig-Thurau等（2004）将网络口碑定义为潜在、现有或过去的消费者通过互联网发布的、关于产品或企业的任何正面或负面陈述，这些陈述可以被大量的个人和机构看到。在线评论是网络口碑中最常见、也最受研究关注的一种形式。Chen和Xie（2008）认为，在线消费者评论是用户根据个人使用经历发布的产品信息，可以看作营销沟通组合中的一种新要素；Mudambi和Schuff（2010）将在线评论定义为消费者在企业网站或第三方网站上发布的产品评价。 / 以上三种界定都包含三层含义：评论由消费者发布，内容来自其购买和使用经历，并在网络平台上公开展示。与传统口碑相比，在线评论的传播范围更广，一条评论可以被所有浏览商品页面的人看到；评论可以长期保存，消费者能够同时查看大量历史评论；发布者大多是陌生人，消费者无法像判断熟人意见那样判断其可靠性。相较于社交媒体上的分享内容，电商平台与点评网站的在线评论多围绕具体商品展开，通常由评分和文字组合而成，并由平台统一展示。由于评论数量庞大且来源分散，平台需要对这些评论进行进一步整理与呈现，AI摘要便是其中形式之一。 / 1.2 在线评论的维度 / 在线评论包含的信息较多，学者们一般把它拆成若干维度分别测量。Babić Rosario等（2016）对96项研究的1532个效应量进行元分析时，把口碑指标归纳为数量、效价、数量与效价的组合以及离散度四类。更早的Floyd等（2014）对26项实证研究进行元分析时，以评论效价和评论数量作为两个基本指标。以上种种指标均可归类为反映评论所包含的信息内容。 / 此外，信息质量研究将信息的表达方式视为信息质量的一个维度。Wang和Strong（1996）把信息质量分为内在、情境、表达和可获得性四类，其中表达质量既包括格式上的简洁和一致，也包括含义上的可解释和易理解，可获得性质量则指信息是否容易获取。 / 据此，本文把在线评论的维度分为信息维度和呈现维度两类。信息维度包括评论数量、评论效价、评论离散度、评论内容和评论者特征五个方面，其中前三个描述一组评论的整体情况，后两个描述单条评论的特点；呈现维度指评论向消费者展示的形式，也分为若干方面。 / 评论数量指某一商品获得的评论条数，通常用评论总数或一段时间内新增的评论数衡量，反映商品受关注的程度。评论效价指评论的正负倾向，常用平均评分、好评率或正负评论的比例衡量。Liu（2006）研究电影口碑时，分别用评论条数和正负评论的比例衡量数量和效价；Chevalier和Mayzlin（2006）则用平均星级以及一星、五星评论所占的比例衡量效价。Babić Rosario等（2016）指出，有些研究用“五星评论的条数”衡量效价，这类指标实际上同时包含了数量信息，应当单独作为“数量与效价的组合”来处理，否则会影响不同研究结论之间的比较。 / 评论离散度指不同消费者的评价之间的分歧程度，一般用评分的方差或标准差衡量。两件商品的评论数量和平均评分可能相同，但一件商品的评价比较一致，另一件商品好评和差评都很多，消费者从中得到的信息并不一样。 / 评论内容指评论文本本身的特征，是研究最多的维度，常用指标包括评论长度或深度、评论质量、可读性和情感倾向等。Mudambi和Schuff（2010）用评论字数衡量评论深度；Park等（2007）在实验中按论据是否客观、具体、有理由支撑来区分高质量评论和低质量评论；Korfiatis等（2012）用可读性指数衡量评论是否容易读懂；郝媛媛等（2010）通过文本挖掘提取评论的情感倾向和主客观表达等特征。 / 评论者特征指发布评论的消费者本身的信息，如评论者等级、历史评论数量、是否公开身份以及在平台上获得的认可等。这类信息一般显示在评论旁边，消费者会据此判断评论者是否可靠。 / 呈现维度与信息维度相互独立，同样的评论内容可以有不同的展示形式。在线评论研究中已有学者把呈现形式作为评论的一个特征，Xu等（2015）就把文字、图文和视频称为评论的不同呈现格式。呈现形式有的由评论者决定，如是否上传图片；有的由平台决定，如评分汇总、评论排序和评论摘要。由于本文研究的AI评论摘要属于后者，下一节对呈现维度单独展开梳理。 / 1.3 在线评论的呈现形式 / 呈现形式是呈现维度在平台上的具体表现。同样的评论内容，展示方式不同，消费者获取的信息和阅读顺序也会不同。根据平台实践和已有研究，本文从单条评论和多条评论两个层面梳理在线评论的呈现形式：前者关注单条评论的呈现载体和结构，后者关注平台对大量评论的汇总、排序和归纳方式。 / 单条评论的呈现首先体现在载体上。在线评论经历了从纯文字到图文结合、再到视频的变化，目前淘宝、京东等平台都允许消费者在评论中上传图片和视频。Xu等（2015）通过实验比较了文字评论、图文评论和视频评论三种呈现方式，发现消费者对视频评论的可信度和说服力评价更高，并且这种差异会随产品类型而变化。 / 单条评论的呈现还体现在结构上。多数平台的评论是消费者自由撰写的一段文字，也有平台要求按固定栏目填写，如分别填写优点和缺点，或对外观、性能等属性分别打分，这类评论称为结构化评论。刘亚男等（2022）通过组间实验比较了结构化评论和非结构化评论，发现对于体验型产品，结构化评论能提高评论深度和消费者的感知诊断性，对于搜索型产品则作用不明显。此外，国内电商平台普遍提供追加评论功能，消费者可以在初次评论一段时间后补充使用体验，使一条评论在时间上分成前后两部分。王长征等（2015）研究了消费者对追加评论有用性的感知，石文华等（2016）对初次评论和追加评论进行了比较，追加评论已经成为国内在线评论研究的一个专门方向。 / 多条评论层面的呈现形式主要有三类。一是评分汇总，平台通常在评论区顶部展示平均星级、评论总数和各星级的分布，消费者往往先看汇总评分，再看具体评论。Qiu等（2012）通过实验发现，当汇总评分与单条评论的倾向相矛盾时，消费者会降低对这条评论的可信度和诊断性判断，而且这种影响对正面评论更明显。这说明消费者会把汇总信息和单条评论放在一起理解。 / 二是评论的排序与组合。平台一般提供按时间、按有用性投票或按评分筛选等排序方式，消费者实际看到的只是排在前面的一部分评论。Purnawirawan等（2012）把消费者看到的多条评论作为一个“评论集合”来研究，发现集合中正负评论的比例和排列顺序都会影响消费者对整组评论的评价：正面或负面占多数的集合比正负各半的集合评价更高，把负面评论放在中间、首尾放正面评论的排列方式也能提高评价。 / 三是对评论内容进行归纳。一些平台从评论中提取高频词，生成“质量很好”“尺码偏大”等评论标签，并标注提及次数。刘景方等（2016）研究了用户评论标签摘要系统的有效性，这类系统按标签对评论进行归纳，帮助用户较快了解评论的主要观点。标签保留了评论中的具体属性信息，形式上是关键词的罗列。近年来出现的AI评论摘要更进一步，平台直接把多条评论的观点写成一段文字或若干条目，消费者不需要阅读原文就能了解评论的大致情况。AI评论摘要的相关研究放在第2节中梳理。 / 总体而言，在线评论呈现形式的研究对象已从单条评论扩展到由多条评论组成的评论集合，平台对评论的加工程度也不断提高，从展示原文、汇总评分、提取标签发展到直接生成摘要。加工程度越高，消费者获取的信息越依赖平台的组织方式。 / 在线评论呈现形式的研究覆盖了载体、结构、评分汇总、排序和标签等多种形式，研究对象多为单条评论或原始评论列表，对平台加工后形成的摘要关注较少。从信息维度看，AI评论摘要实际上是把一组评论的效价、离散度和评论内容中涉及的商品属性压缩成一份概括。从呈现维度看，结构化评论按优缺点或按属性组织单条评论，与AI评论摘要中按优缺点分组、按属性分项的做法组织逻辑相近，区别在于后者组织的是多条评论归纳后的内容。 / 据此，本文研究的在线评论限定为电商平台上的商品评论，研究对象是由多条评论归纳而成的AI评论摘要。在信息维度上，实验中各组商品的评论数量、平均评分以及摘要所依据的评价内容保持一致；在呈现维度上，本文研究的是AI评论摘要内部的信息组织方式。 / 2． AI评论摘要 / 本节先梳理AI评论摘要的定义和发展，再梳理消费者对AI评论摘要的反应，最后梳理摘要呈现方式的研究和平台做法，并由此引出本文研究的两个方面。 / 2.1 AI评论摘要的定义与发展 / “评论摘要”的概念最早来自计算机领域的观点摘要研究。Hu和Liu（2004）把评论摘要界定为一种基于商品特征的摘要：先找出消费者在评论中评价过的商品特征，再判断每个特征上的评价是正面还是负面，最后按特征汇总。Kim等（2011）在综述中采用了更宽的界定，把对大量观点生成简洁、易于理解的摘要的研究都归入观点摘要，并指出摘要可以是汇总后的情感评分，也可以是按属性或主题分解的结构化摘要，或是一段文字摘要。这一领域的定义着眼于摘要任务和输出形式。 / 围绕这一任务，摘要技术经历了几个阶段，摘要的输出形式也随之变化。Hu和Liu（2004）的摘要按商品特征逐项列出正面和负面评价的数量及例句；Liu等（2005）开发的Opinion Observer系统把不同商品在各属性上的优缺点做成可视化比较。之后的研究转向生成连贯的摘要文本，Ganesan等（2010）提出的Opinosis方法利用评论中反复出现的表达生成简短概括；Chu和Liu（2019）提出的MeanSum模型在没有人工摘要作为训练样本的情况下，也能生成多条评论的综合摘要。 / 大语言模型得到应用后，研究重点转向摘要是否忠实于原始评论。Hosking等（2024）先检索有代表性的评论片段，再由大模型据此生成摘要，使摘要内容能追溯到原文；Siledar等（2024）建立了观点摘要的评价数据集，从忠实性、属性覆盖和情感一致性等方面评价摘要质量。时至今日，按属性列出、按正负对比和连续文本这几种输出形式的呈现，在今天平台上的AI评论摘要中都能看到。 / 生成式AI进入电商平台以后，营销和信息管理领域开始把AI评论摘要作为一种新的平台信息来研究，界定的角度也随之变化。Wang和Wang（2025）以亚马逊2023年上线的功能为对象，将其描述为平台利用人工智能为消费者评论生成简洁摘要，并在过滤虚假或无用评论后置于评论区顶部，作用是从大量评论中提取关键信息。Jia、Zhao和Zhang（2026）认为AI评论摘要是生成式技术分析大量消费者评论后浓缩而成的简洁段落或要点，并把它看作在线评论的“代理”。Jia、Chi和Chi（2025）按生成来源把评论摘要分为AI生成和人工生成两类，说明“AI”一词限定的是摘要的生成主体。国内研究多使用“人工智能生成评论总结”或“AI评论总结”等说法。张鹏和刘春慧（2026）认为，人工智能生成评论总结把分散、碎片化的个体评论转化为聚合性结论，它与个体评论的本质区别在于算法对信息的筛选、重组与建构，具体包括三个方面：识别评论的效价，把模糊的情感表达转为正面、中性或负面的明确分类；抽取评论涉及的维度，如质量、物流和服务，并把分散的内容归类整合；按一定规则对效价信息和维度信息进行二次编排，形成有逻辑的总结框架。 / 比较上述界定，各研究在三点上基本一致：摘要的对象是同一商品或服务的多条评论，生成者是平台的算法，产出是比原始评论简短得多的概括内容。不同之处在于，计算机领域从任务和输出形式出发，营销和信息管理领域从来源和功能出发，多数默认摘要由生成式AI产生。Kim等（2011）和Jia、Zhao和Zhang（2026）提到摘要可以是评分、段落或要点等不同形式，张鹏和刘春慧（2026）把“二次编排”列为摘要的特征之一。 / 结合上述研究和平台实践，本文统一使用“AI评论摘要”一词，将其定义为平台利用人工智能技术，对某一商品或服务的多条用户评论进行归纳后形成、并展示给消费者的摘要内容，主要包括评论中的共同观点、涉及的商品属性和评论效价。与在线评论相比，AI评论摘要由平台生成，内容是对多条评论的整合。 / 2.2 消费者对AI评论摘要的反应 / 在消费者对AI评论摘要的反应方面，不少研究从摘要来源入手。Jia、Chi和Chi（2025）通过三项酒店预订情境实验发现，人工摘要在部分条件下更容易获得消费者信任，但在负面评价条件下，AI摘要和人工摘要带来的预订意愿没有显著差异。Chai等（2026）把措辞也考虑进来，发现当摘要用“多数”等文字形式表达概率时，消费者对AI摘要的反应反而比对人工摘要更积极，感知客观性和信任在其中起中介作用。Jia、Zhao和Zhang（2026）则不比较来源，而是调查了713名消费者对AI摘要本身的感知，发现透明性、可理解性和便利性会影响消费者对摘要可信度的判断。 / 另有研究利用平台数据考察摘要上线后的实际效果。Wang和Wang（2025）用亚马逊商品面板数据和双重差分方法，发现引入AI评论摘要后商品的购买行为指标有所改善；张鹏和古新成（2026）以酒店平台为对象，发现AI评论总结上线后，用户评论数量的增速下降了。前者考察的是消费者的购买行为，后者考察的是评论撰写行为。 / 总的来看，计算机领域的研究主要关注摘要的生成方法及其准确性；营销和信息管理领域的研究主要关注消费者对AI摘要的信任，以及平台引入摘要后消费者购买和评论行为的变化，对摘要内部怎样组织信息关注较少。 / 2.3 AI评论摘要的呈现模式 / 学术研究中对AI评论摘要呈现方式的讨论还不多。张鹏和刘春慧（2026）按信息组织逻辑把摘要的呈现结构分为列表体和叙事体两类：列表体用相互独立的条目逐项陈列商品属性和对应评价，如“优势：续航时间较长，且性价比很高；劣势：有用户反馈机身偏重”；叙事体则借助属性之间的关联，用连贯的段落叙述评价。他们通过眼动实验比较了两种呈现结构以及正面在前和负面在前两种效价顺序，发现呈现结构、效价顺序和产品类型会共同影响消费者对正面内容的视觉注意，并进一步影响购买意愿。 / 从平台实践看，AI评论摘要的组织方式主要有四种：App Store用一段连续文字概括评价；Naver Shopping按商品属性分条列出；美团按优点和缺点分栏；Tripadvisor先用一段话给出总体评价，再按属性列出细项。比较这四种做法，可以看到它们在两个方面不同。第一个方面是分组依据，即摘要内容按什么分组。评论信息由商品属性和评论效价两种成分构成，Hu和Liu（2004）的评论摘要就是按商品属性汇总正负评价，优缺点分栏或按属性打分。摘要可以按属性分组，可以按效价分组，也可以不分组。第二个方面是有无独立总览，即分组内容之前是否另有一段总体评价。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。 / 用这两个方面可以描述上述四种做法：App Store不分组，整段文字本身就是对评价的总体概括，本文称为整体概括式；Naver Shopping按属性分组、没有独立总览，称为属性分项式；美团按效价分组、没有独立总览，称为优缺点分组式；Tripadvisor有独立总览，后面的细项按属性分组，称为总分结合式。总分结合式后面的细项也可以按效价分组，本文据此把它分为属性型和优缺点型两种。与张鹏和刘春慧（2026）的划分相比，他们的叙事体对应本文的整体概括式，列表体在本文中按分组依据分成属性分项式和优缺点分组式，总分结合式是本文增加的一类。 / 本文从分组依据和有无独立总览两个方面研究呈现模式，因为这两个方面决定了消费者打开摘要后先看到什么、按什么顺序找信息，也是各平台做法差别最大的地方。实验把两个方面交叉：分组依据取按属性和按优缺点两个水平，独立总览取有和无两个水平，得到属性分项式、优缺点分组式以及属性型和优缺点型两种总分结合式，共四组。整体概括式不分组作为补充对照组，用来比较分条组织和连续段落的差别。 / 3． 信息采纳模型 / 本文以信息采纳模型为理论基础。本节介绍模型的提出和后续扩展，并说明本文怎样使用这一模型。 / 3.1 模型的提出 / 信息采纳模型由Sussman和Siegal（2003）提出，用来解释个体在接收到信息后为什么会采纳这些信息。该模型结合了技术接受模型（Davis，1989）和精细加工可能性模型（Petty和Cacioppo，1986）。精细加工可能性模型认为，个体处理信息有中心路径和边缘路径两种方式，前者主要依据信息内容本身进行判断，后者主要依据信息来源等外部线索进行判断。信息采纳模型据此把论据质量和来源可信度作为前因变量，分别对应中心路径和边缘路径；同时借鉴技术接受模型中感知有用性影响使用意向的思路，把信息有用性作为中介变量，把信息采纳作为结果变量。Sussman和Siegal（2003）以企业员工收到的建议邮件为对象进行检验，发现论据质量和来源可信度会通过信息有用性影响员工对建议的采纳，员工的专业知识和涉入程度会调节这一过程。 / 3.2 模型的扩展与应用 / 此后，学者们在不同情境中对该模型进行了检验和扩展。Bhattacherjee和Sanford（2006）把精细加工可能性模型用于信息技术接受研究，用论据质量和来源可信度解释用户的感知有用性和态度，并发现用户的专业知识和工作相关性会调节这两条路径的作用。Zhang和Watts（2008）以两个在线社区为对象，发现论据质量和来源可信度都会影响成员对社区信息的采纳，当新信息与已有认知不一致或成员带着明确目的搜索时，成员对来源可信度的依赖会减弱。Cheung等（2008）把模型用于在线消费者社区，发现论据质量中的相关性和全面性对信息有用性的影响较大，而来源可信度的影响不显著。Erkan和Evans（2016）在社交媒体情境中提出扩展的信息采纳模型，加入了信息需求和对信息的态度两个变量，并把购买意愿作为信息采纳之后的结果。 / 从已有研究看，信息采纳模型已经从组织内部的邮件沟通扩展到在线社区、在线评论和社交媒体等情境，“信息有用性影响信息采纳”这一核心路径得到了反复验证。这些研究的前因变量主要是论据质量、来源可信度等内容与来源特征，信息的呈现形式很少被考虑。因此，本文以信息采纳模型为理论基础，把AI评论摘要的呈现模式作为影响消费者处理信息的前因，保留“感知有用性—采纳意愿”这一核心路径。 / 4． 感知有用性 / 4.1 感知有用性的定义 / 感知有用性最早来自技术接受模型。Davis（1989）将其定义为个体认为使用某一特定系统能够提高其工作绩效的程度。Sussman和Siegal（2003）把这一概念用到信息采纳研究中，提出了信息有用性，指个体认为使用某条信息能够帮助自己更好地完成任务的程度。在在线评论研究中，学者们常用“评论有用性”这一概念，Mudambi和Schuff（2010）将有用的评论定义为能够帮助消费者完成购买决策的评论。三个概念的适用对象依次为信息系统、一般信息和在线评论，核心含义一致，均指个体对某一对象能否帮助自己完成任务的判断。本文的研究对象为AI评论摘要，统一使用“感知有用性”这一表述，文中引用的信息有用性和评论有用性研究均按这一含义理解。 / 4.2 感知有用性的测量 / 已有研究测量有用性主要有两种方式。第一种是利用平台上的“有帮助”投票数或投票比例，如Mudambi和Schuff（2010）、Korfiatis等（2012）的研究，这类数据反映的是其他用户对单条评论的评价。第二种是用问卷测量消费者自己感知到的有用程度。Davis（1989）开发的感知有用性量表包括提高工作效率、提高工作绩效和更容易完成工作等题项；Cheung等（2008）结合在线评论情境，从“有价值的”“有信息量的”“有帮助的”三个方面测量信息有用性。多数研究把感知有用性作为单维变量处理。 / 4.3 感知有用性的影响因素 / 在有用性的影响因素中，研究最多的是评论内容本身。Mudambi和Schuff（2010）发现评论深度和评分极端程度会影响评论有用性，且评论深度对搜索型产品的作用更强。Korfiatis等（2012）发现，可读性对“有帮助”投票比例的影响比评论长度更大。郝媛媛等（2010）用国内影评数据得出的结论是，积极的情感倾向、较高的正负情感混杂度和较长的平均句长都会提高评论有用性。Cheung等（2008）则从论据质量的角度，发现相关性和全面性的影响最大。 / 也有研究关注信息来源和评论者特征的作用。Sussman和Siegal（2003）发现来源可信度会影响信息有用性；Pan和Zhang（2011）发现评论者在文字中表现出的创新性与评论有用性呈倒U型关系；Ghose和Ipeirotis（2011）把文本特征和评论者信息放在一起分析，发现主观性、可读性、拼写错误和评论者的历史信息都有影响；殷国鹏（2012）基于豆瓣网数据，发现评论与平均星级的偏差、评论者的社会特征也会起作用。 / 从呈现方式解释有用性的研究相对较少。刘亚男等（2022）发现，对于体验型产品，结构化呈现的评论能提高感知诊断性和感知有用性；Jia、Zhao和Zhang（2026）发现，AI摘要的可理解性和便利性会提高消费者对摘要的信任，并提高其感知帮助程度。 /  /  / 5 采纳意愿 / 5.1 采纳意愿的定义与测量 / 信息采纳指个体有目的地使用信息的过程（Sussman和Siegal，2003）。在在线评论情境中，Cheung等（2008）把信息采纳理解为消费者接受评论中的观点，并据此作出购买相关的决策。Erkan和Evans（2016）进一步区分了信息采纳和购买意愿，认为消费者先采纳信息，再形成购买意愿。在测量上，部分研究测量的是消费者已经发生的采纳行为，如Cheung等（2008）的题项询问消费者是否同意评论观点、是否按照评论建议采取过行动；也有研究测量消费者在当前情境下的采纳意愿，如刘亚男等（2022）测量的评论接受意愿，以及Jia、Zhao和Zhang（2026）测量的摘要采纳意愿。 / 5.2 采纳意愿的影响因素 / 信息有用性是影响信息采纳最直接的因素。Sussman和Siegal（2003）发现信息有用性在论据质量、来源可信度与信息采纳之间起中介作用；Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中发现，信息有用性会正向影响信息采纳；Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，摘要可信度会通过感知帮助程度影响消费者的采纳意愿。除有用性外，Filieri和McLeay（2014）发现信息的准确性、增值性、相关性、及时性以及产品排名都会影响游客对评论信息的采纳；Filieri（2015）发现消费者主要根据信息质量判断评论能否帮助自己识别商品的特点，即信息诊断性，而诊断性会进一步影响信息采纳。 /  /  / 6． 文献述评 / 综上所述，在线评论、信息采纳和感知有用性的研究基础比较扎实，概念、维度和量表都可以借鉴。评论的载体、结构、汇总评分和排列方式对消费者判断的影响，已在原始评论情境中得到较多检验，AI摘要情境中的相关研究还很少。AI评论摘要研究主要比较摘要的来源和平台引入摘要的效果，对呈现方式只比较过列表体和叙事体，摘要的分组依据和独立总览各自起什么作用还缺少检验。感知有用性和采纳意愿的研究也很少以整份AI摘要为对象。 / 基于此，本文以信息采纳模型为理论基础，以AI评论摘要的分组依据和有无独立总览为自变量，感知有用性为中介变量，消费者采纳意愿为因变量，通过2×2组间实验检验两个自变量的主效应和交互作用，以及感知有用性的中介作用，并以整体概括式作为补充对照组。 / 参考文献 / [1] 郝媛媛, 叶强, 李一军. 基于影评数据的在线评论有用性影响因素研究[J]. 管理科学学报, 2010, 13(8): DOI: 10.17705/1jais.00149. | 二、国内外研究现状概述 / 本文关心的是消费者怎样看待和使用AI评论摘要。按照“信息本身—信息的呈现—信息的采纳”的顺序，本部分先梳理在线评论的研究，再梳理AI评论摘要的研究，然后介绍信息采纳模型，并分别梳理模型中的感知有用性和采纳意愿，最后进行述评。 / 1 在线评论 / 1.1 在线评论的定义 / 在线评论源于口碑传播。传统口碑是消费者之间面对面的、非商业性的信息交流，互联网普及后，这种交流逐渐转移到线上。Hennig-Thurau等（2004）将网络口碑定义为潜在、现有或过去的消费者通过互联网发布的、关于产品或企业的任何正面或负面陈述，这些陈述可以被大量的个人和机构看到。在线评论是网络口碑中最常见、也最受研究关注的一种形式。Chen和Xie（2008）认为，在线消费者评论是用户根据个人使用经历发布的产品信息，可以看作营销沟通组合中的一种新要素；Mudambi和Schuff（2010）将在线评论定义为消费者在企业网站或第三方网站上发布的产品评价。 / 以上三种界定都包含三层含义：评论由消费者发布，内容来自其购买和使用经历，并在网络平台上公开展示。与传统口碑相比，在线评论的传播范围更广，一条评论可以被所有浏览商品页面的人看到；评论可以长期保存，消费者能够同时查看大量历史评论；发布者大多是陌生人，消费者无法像判断熟人意见那样判断其可靠性。相较于社交媒体上的分享内容，电商平台与点评网站的在线评论多围绕具体商品展开，通常由评分和文字组合而成，并由平台统一展示。由于评论数量庞大且来源分散，平台需要对这些评论进行进一步整理与呈现，AI摘要便是其中形式之一。 / 1.2 在线评论的维度 / 在线评论包含的信息较多，学者们一般把它拆成若干维度分别测量。Babić Rosario等（2016）对96项研究的1532个效应量进行元分析时，把口碑指标归纳为数量、效价、数量与效价的组合以及离散度四类。更早的Floyd等（2014）对26项实证研究进行元分析时，以评论效价和评论数量作为两个基本指标。以上种种指标均可归类为反映评论所包含的信息内容。 / 此外，信息质量研究将信息的表达方式视为信息质量的一个维度。Wang和Strong（1996）把信息质量分为内在、情境、表达和可获得性四类，其中表达质量既包括格式上的简洁和一致，也包括含义上的可解释和易理解，可获得性质量则指信息是否容易获取。 / 据此，本文把在线评论的维度分为信息维度和呈现维度两类。信息维度包括评论数量、评论效价、评论离散度、评论内容和评论者特征五个方面，其中前三个描述一组评论的整体情况，后两个描述单条评论的特点；呈现维度指评论向消费者展示的形式，也分为若干方面。 / 评论数量指某一商品获得的评论条数，通常用评论总数或一段时间内新增的评论数衡量，反映商品受关注的程度。评论效价指评论的正负倾向，常用平均评分、好评率或正负评论的比例衡量。Liu（2006）研究电影口碑时，分别用评论条数和正负评论的比例衡量数量和效价；Chevalier和Mayzlin（2006）则用平均星级以及一星、五星评论所占的比例衡量效价。Babić Rosario等（2016）指出，有些研究用“五星评论的条数”衡量效价，这类指标实际上同时包含了数量信息，应当单独作为“数量与效价的组合”来处理，否则会影响不同研究结论之间的比较。 / 评论离散度指不同消费者的评价之间的分歧程度，一般用评分的方差或标准差衡量。两件商品的评论数量和平均评分可能相同，但一件商品的评价比较一致，另一件商品好评和差评都很多，消费者从中得到的信息并不一样。 / 评论内容指评论文本本身的特征，是研究最多的维度，常用指标包括评论长度或深度、评论质量、可读性和情感倾向等。Mudambi和Schuff（2010）用评论字数衡量评论深度；Park等（2007）在实验中按论据是否客观、具体、有理由支撑来区分高质量评论和低质量评论；Korfiatis等（2012）用可读性指数衡量评论是否容易读懂；郝媛媛等（2010）通过文本挖掘提取评论的情感倾向和主客观表达等特征。 / 评论者特征指发布评论的消费者本身的信息，如评论者等级、历史评论数量、是否公开身份以及在平台上获得的认可等。这类信息一般显示在评论旁边，消费者会据此判断评论者是否可靠。 / 呈现维度与信息维度相互独立，同样的评论内容可以有不同的展示形式。在线评论研究中已有学者把呈现形式作为评论的一个特征，Xu等（2015）就把文字、图文和视频称为评论的不同呈现格式。呈现形式有的由评论者决定，如是否上传图片；有的由平台决定，如评分汇总、评论排序和评论摘要。由于本文研究的AI评论摘要属于后者，下一节对呈现维度单独展开梳理。 / 1.3 在线评论的呈现形式 / 呈现形式是呈现维度在平台上的具体表现。同样的评论内容，展示方式不同，消费者获取的信息和阅读顺序也会不同。根据平台实践和已有研究，本文从单条评论和多条评论两个层面梳理在线评论的呈现形式：前者关注单条评论的呈现载体和结构，后者关注平台对大量评论的汇总、排序和归纳方式。 / 单条评论的呈现首先体现在载体上。在线评论经历了从纯文字到图文结合、再到视频的变化，目前淘宝、京东等平台都允许消费者在评论中上传图片和视频。Xu等（2015）通过实验比较了文字评论、图文评论和视频评论三种呈现方式，发现消费者对视频评论的可信度和说服力评价更高，并且这种差异会随产品类型而变化。 / 单条评论的呈现还体现在结构上。多数平台的评论是消费者自由撰写的一段文字，也有平台要求按固定栏目填写，如分别填写优点和缺点，或对外观、性能等属性分别打分，这类评论称为结构化评论。刘亚男等（2022）通过组间实验比较了结构化评论和非结构化评论，发现对于体验型产品，结构化评论能提高评论深度和消费者的感知诊断性，对于搜索型产品则作用不明显。此外，国内电商平台普遍提供追加评论功能，消费者可以在初次评论一段时间后补充使用体验，使一条评论在时间上分成前后两部分。王长征等（2015）研究了消费者对追加评论有用性的感知，石文华等（2016）对初次评论和追加评论进行了比较，追加评论已经成为国内在线评论研究的一个专门方向。 / 多条评论层面的呈现形式主要有三类。一是评分汇总，平台通常在评论区顶部展示平均星级、评论总数和各星级的分布，消费者往往先看汇总评分，再看具体评论。Qiu等（2012）通过实验发现，当汇总评分与单条评论的倾向相矛盾时，消费者会降低对这条评论的可信度和诊断性判断，而且这种影响对正面评论更明显。这说明消费者会把汇总信息和单条评论放在一起理解。 / 二是评论的排序与组合。平台一般提供按时间、按有用性投票或按评分筛选等排序方式，消费者实际看到的只是排在前面的一部分评论。Purnawirawan等（2012）把消费者看到的多条评论作为一个“评论集合”来研究，发现集合中正负评论的比例和排列顺序都会影响消费者对整组评论的评价：正面或负面占多数的集合比正负各半的集合评价更高，把负面评论放在中间、首尾放正面评论的排列方式也能提高评价。 / 三是对评论内容进行归纳。一些平台从评论中提取高频词，生成“质量很好”“尺码偏大”等评论标签，并标注提及次数。刘景方等（2016）研究了用户评论标签摘要系统的有效性，这类系统按标签对评论进行归纳，帮助用户较快了解评论的主要观点。标签保留了评论中的具体属性信息，形式上是关键词的罗列。近年来出现的AI评论摘要更进一步，平台直接把多条评论的观点写成一段文字或若干条目，消费者不需要阅读原文就能了解评论的大致情况。AI评论摘要的相关研究放在第2节中梳理。 / 总体而言，在线评论呈现形式的研究对象已从单条评论扩展到由多条评论组成的评论集合，平台对评论的加工程度也不断提高，从展示原文、汇总评分、提取标签发展到直接生成摘要。加工程度越高，消费者获取的信息越依赖平台的组织方式。 / 在线评论呈现形式的研究覆盖了载体、结构、评分汇总、排序和标签等多种形式，研究对象多为单条评论或原始评论列表，对平台加工后形成的摘要关注较少。从信息维度看，AI评论摘要实际上是把一组评论的效价、离散度和评论内容中涉及的商品属性压缩成一份概括。从呈现维度看，结构化评论按优缺点或按属性组织单条评论，与AI评论摘要中按优缺点分组、按属性分项的做法组织逻辑相近，区别在于后者组织的是多条评论归纳后的内容。 / 据此，本文研究的在线评论限定为电商平台上的商品评论，研究对象是由多条评论归纳而成的AI评论摘要。在信息维度上，实验中各组商品的评论数量、平均评分以及摘要所依据的评价内容保持一致；在呈现维度上，本文研究的是AI评论摘要内部的信息组织方式。 / 2． AI评论摘要 / 本节先梳理AI评论摘要的定义和发展，再梳理消费者对AI评论摘要的反应，最后梳理摘要呈现方式的研究和平台做法，并由此引出本文研究的两个方面。 / 2.1 AI评论摘要的定义与发展 / “评论摘要”的概念最早来自计算机领域的观点摘要研究。Hu和Liu（2004）把评论摘要界定为一种基于商品特征的摘要：先找出消费者在评论中评价过的商品特征，再判断每个特征上的评价是正面还是负面，最后按特征汇总。Kim等（2011）在综述中采用了更宽的界定，把对大量观点生成简洁、易于理解的摘要的研究都归入观点摘要，并指出摘要可以是汇总后的情感评分，也可以是按属性或主题分解的结构化摘要，或是一段文字摘要。这一领域的定义着眼于摘要任务和输出形式。 / 围绕这一任务，摘要技术经历了几个阶段，摘要的输出形式也随之变化。Hu和Liu（2004）的摘要按商品特征逐项列出正面和负面评价的数量及例句；Liu等（2005）开发的Opinion Observer系统把不同商品在各属性上的优缺点做成可视化比较。之后的研究转向生成连贯的摘要文本，Ganesan等（2010）提出的Opinosis方法利用评论中反复出现的表达生成简短概括；Chu和Liu（2019）提出的MeanSum模型在没有人工摘要作为训练样本的情况下，也能生成多条评论的综合摘要。 / 大语言模型得到应用后，研究重点转向摘要是否忠实于原始评论。Hosking等（2024）先检索有代表性的评论片段，再由大模型据此生成摘要，使摘要内容能追溯到原文；Siledar等（2024）建立了观点摘要的评价数据集，从忠实性、属性覆盖和情感一致性等方面评价摘要质量。时至今日，按属性列出、按正负对比和连续文本这几种输出形式的呈现，在今天平台上的AI评论摘要中都能看到。 / 生成式AI进入电商平台以后，营销和信息管理领域开始把AI评论摘要作为一种新的平台信息来研究，界定的角度也随之变化。Wang和Wang（2025）以亚马逊2023年上线的功能为对象，将其描述为平台利用人工智能为消费者评论生成简洁摘要，并在过滤虚假或无用评论后置于评论区顶部，作用是从大量评论中提取关键信息。Jia、Zhao和Zhang（2026）认为AI评论摘要是生成式技术分析大量消费者评论后浓缩而成的简洁段落或要点，并把它看作在线评论的“代理”。Jia、Chi和Chi（2025）按生成来源把评论摘要分为AI生成和人工生成两类，说明“AI”一词限定的是摘要的生成主体。国内研究多使用“人工智能生成评论总结”或“AI评论总结”等说法。张鹏和刘春慧（2026）认为，人工智能生成评论总结把分散、碎片化的个体评论转化为聚合性结论，它与个体评论的本质区别在于算法对信息的筛选、重组与建构，具体包括三个方面：识别评论的效价，把模糊的情感表达转为正面、中性或负面的明确分类；抽取评论涉及的维度，如质量、物流和服务，并把分散的内容归类整合；按一定规则对效价信息和维度信息进行二次编排，形成有逻辑的总结框架。 / 比较上述界定，各研究在三点上基本一致：摘要的对象是同一商品或服务的多条评论，生成者是平台的算法，产出是比原始评论简短得多的概括内容。不同之处在于，计算机领域从任务和输出形式出发，营销和信息管理领域从来源和功能出发，多数默认摘要由生成式AI产生。Kim等（2011）和Jia、Zhao和Zhang（2026）提到摘要可以是评分、段落或要点等不同形式，张鹏和刘春慧（2026）把“二次编排”列为摘要的特征之一。 / 结合上述研究和平台实践，本文统一使用“AI评论摘要”一词，将其定义为平台利用人工智能技术，对某一商品或服务的多条用户评论进行归纳后形成、并展示给消费者的摘要内容，主要包括评论中的共同观点、涉及的商品属性和评论效价。与在线评论相比，AI评论摘要由平台生成，内容是对多条评论的整合。 / 2.2 消费者对AI评论摘要的反应 / 在消费者对AI评论摘要的反应方面，不少研究从摘要来源入手。Jia、Chi和Chi（2025）通过三项酒店预订情境实验发现，人工摘要在部分条件下更容易获得消费者信任，但在负面评价条件下，AI摘要和人工摘要带来的预订意愿没有显著差异。Chai等（2026）把措辞也考虑进来，发现当摘要用“多数”等文字形式表达概率时，消费者对AI摘要的反应反而比对人工摘要更积极，感知客观性和信任在其中起中介作用。Jia、Zhao和Zhang（2026）则不比较来源，而是调查了713名消费者对AI摘要本身的感知，发现透明性、可理解性和便利性会影响消费者对摘要可信度的判断。 / 另有研究利用平台数据考察摘要上线后的实际效果。Wang和Wang（2025）用亚马逊商品面板数据和双重差分方法，发现引入AI评论摘要后商品的购买行为指标有所改善；张鹏和古新成（2026）以酒店平台为对象，发现AI评论总结上线后，用户评论数量的增速下降了。前者考察的是消费者的购买行为，后者考察的是评论撰写行为。 / 总的来看，计算机领域的研究主要关注摘要的生成方法及其准确性；营销和信息管理领域的研究主要关注消费者对AI摘要的信任，以及平台引入摘要后消费者购买和评论行为的变化，对摘要内部怎样组织信息关注较少。 / 2.3 AI评论摘要的呈现模式 / 学术研究中对AI评论摘要呈现方式的讨论还不多。张鹏和刘春慧（2026）按信息组织逻辑把摘要的呈现结构分为列表体和叙事体两类：列表体用相互独立的条目逐项陈列商品属性和对应评价，如“优势：续航时间较长，且性价比很高；劣势：有用户反馈机身偏重”；叙事体则借助属性之间的关联，用连贯的段落叙述评价。他们通过眼动实验比较了两种呈现结构以及正面在前和负面在前两种效价顺序，发现呈现结构、效价顺序和产品类型会共同影响消费者对正面内容的视觉注意，并进一步影响购买意愿。 / 从平台实践看，AI评论摘要的组织方式主要有四种：App Store用一段连续文字概括评价；Naver Shopping按商品属性分条列出；美团按优点和缺点分栏；Tripadvisor先用一段话给出总体评价，再按属性列出细项。比较这四种做法，可以看到它们在两个方面不同。第一个方面是分组依据，即摘要内容按什么分组。评论信息由商品属性和评论效价两种成分构成，Hu和Liu（2004）的评论摘要就是按商品属性汇总正负评价，优缺点分栏或按属性打分。摘要可以按属性分组，可以按效价分组，也可以不分组。第二个方面是有无独立总览，即分组内容之前是否另有一段总体评价。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。 / 用这两个方面可以描述上述四种做法：App Store不分组，整段文字本身就是对评价的总体概括，本文称为整体概括式；Naver Shopping按属性分组、没有独立总览，称为属性分项式；美团按效价分组、没有独立总览，称为优缺点分组式；Tripadvisor有独立总览，后面的细项按属性分组，称为总分结合式。总分结合式后面的细项也可以按效价分组，本文据此把它分为属性型和优缺点型两种。与张鹏和刘春慧（2026）的划分相比，他们的叙事体对应本文的整体概括式，列表体在本文中按分组依据分成属性分项式和优缺点分组式，总分结合式是本文增加的一类。 / 本文从分组依据和有无独立总览两个方面研究呈现模式，因为这两个方面决定了消费者打开摘要后先看到什么、按什么顺序找信息，也是各平台做法差别最大的地方。实验把两个方面交叉：分组依据取按属性和按优缺点两个水平，独立总览取有和无两个水平，得到属性分项式、优缺点分组式以及属性型和优缺点型两种总分结合式，共四组。整体概括式不分组作为补充对照组，用来比较分条组织和连续段落的差别。 / 3． 信息采纳模型 / 本文以信息采纳模型为理论基础。本节介绍模型的提出和后续扩展，并说明本文怎样使用这一模型。 / 3.1 模型的提出 / 信息采纳模型由Sussman和Siegal（2003）提出，用来解释个体在接收到信息后为什么会采纳这些信息。该模型结合了技术接受模型（Davis，1989）和精细加工可能性模型（Petty和Cacioppo，1986）。精细加工可能性模型认为，个体处理信息有中心路径和边缘路径两种方式，前者主要依据信息内容本身进行判断，后者主要依据信息来源等外部线索进行判断。信息采纳模型据此把论据质量和来源可信度作为前因变量，分别对应中心路径和边缘路径；同时借鉴技术接受模型中感知有用性影响使用意向的思路，把信息有用性作为中介变量，把信息采纳作为结果变量。Sussman和Siegal（2003）以企业员工收到的建议邮件为对象进行检验，发现论据质量和来源可信度会通过信息有用性影响员工对建议的采纳，员工的专业知识和涉入程度会调节这一过程。 / 3.2 模型的扩展与应用 / 此后，学者们在不同情境中对该模型进行了检验和扩展。Bhattacherjee和Sanford（2006）把精细加工可能性模型用于信息技术接受研究，用论据质量和来源可信度解释用户的感知有用性和态度，并发现用户的专业知识和工作相关性会调节这两条路径的作用。Zhang和Watts（2008）以两个在线社区为对象，发现论据质量和来源可信度都会影响成员对社区信息的采纳，当新信息与已有认知不一致或成员带着明确目的搜索时，成员对来源可信度的依赖会减弱。Cheung等（2008）把模型用于在线消费者社区，发现论据质量中的相关性和全面性对信息有用性的影响较大，而来源可信度的影响不显著。Erkan和Evans（2016）在社交媒体情境中提出扩展的信息采纳模型，加入了信息需求和对信息的态度两个变量，并把购买意愿作为信息采纳之后的结果。 / 从已有研究看，信息采纳模型已经从组织内部的邮件沟通扩展到在线社区、在线评论和社交媒体等情境，“信息有用性影响信息采纳”这一核心路径得到了反复验证。这些研究的前因变量主要是论据质量、来源可信度等内容与来源特征，信息的呈现形式很少被考虑。因此，本文以信息采纳模型为理论基础，把AI评论摘要的呈现模式作为影响消费者处理信息的前因，保留“感知有用性—采纳意愿”这一核心路径。 / 4． 感知有用性 / 4.1 感知有用性的定义 / 感知有用性最早来自技术接受模型。Davis（1989）将其定义为个体认为使用某一特定系统能够提高其工作绩效的程度。Sussman和Siegal（2003）把这一概念用到信息采纳研究中，提出了信息有用性，指个体认为使用某条信息能够帮助自己更好地完成任务的程度。在在线评论研究中，学者们常用“评论有用性”这一概念，Mudambi和Schuff（2010）将有用的评论定义为能够帮助消费者完成购买决策的评论。三个概念的适用对象依次为信息系统、一般信息和在线评论，核心含义一致，均指个体对某一对象能否帮助自己完成任务的判断。本文的研究对象为AI评论摘要，统一使用“感知有用性”这一表述，文中引用的信息有用性和评论有用性研究均按这一含义理解。 / 4.2 感知有用性的测量 / 已有研究测量有用性主要有两种方式。第一种是利用平台上的“有帮助”投票数或投票比例，如Mudambi和Schuff（2010）、Korfiatis等（2012）的研究，这类数据反映的是其他用户对单条评论的评价。第二种是用问卷测量消费者自己感知到的有用程度。Davis（1989）开发的感知有用性量表包括提高工作效率、提高工作绩效和更容易完成工作等题项；Cheung等（2008）结合在线评论情境，从“有价值的”“有信息量的”“有帮助的”三个方面测量信息有用性。多数研究把感知有用性作为单维变量处理。 / 4.3 感知有用性的影响因素 / 在有用性的影响因素中，研究最多的是评论内容本身。Mudambi和Schuff（2010）发现评论深度和评分极端程度会影响评论有用性，且评论深度对搜索型产品的作用更强。Korfiatis等（2012）发现，可读性对“有帮助”投票比例的影响比评论长度更大。郝媛媛等（2010）用国内影评数据得出的结论是，积极的情感倾向、较高的正负情感混杂度和较长的平均句长都会提高评论有用性。Cheung等（2008）则从论据质量的角度，发现相关性和全面性的影响最大。 / 也有研究关注信息来源和评论者特征的作用。Sussman和Siegal（2003）发现来源可信度会影响信息有用性；Pan和Zhang（2011）发现评论者在文字中表现出的创新性与评论有用性呈倒U型关系；Ghose和Ipeirotis（2011）把文本特征和评论者信息放在一起分析，发现主观性、可读性、拼写错误和评论者的历史信息都有影响；殷国鹏（2012）基于豆瓣网数据，发现评论与平均星级的偏差、评论者的社会特征也会起作用。 / 从呈现方式解释有用性的研究相对较少。刘亚男等（2022）发现，对于体验型产品，结构化呈现的评论能提高感知诊断性和感知有用性；Jia、Zhao和Zhang（2026）发现，AI摘要的可理解性和便利性会提高消费者对摘要的信任，并提高其感知帮助程度。 /  /  / 5 采纳意愿 / 5.1 采纳意愿的定义与测量 / 信息采纳指个体有目的地使用信息的过程（Sussman和Siegal，2003）。在在线评论情境中，Cheung等（2008）把信息采纳理解为消费者接受评论中的观点，并据此作出购买相关的决策。Erkan和Evans（2016）进一步区分了信息采纳和购买意愿，认为消费者先采纳信息，再形成购买意愿。在测量上，部分研究测量的是消费者已经发生的采纳行为，如Cheung等（2008）的题项询问消费者是否同意评论观点、是否按照评论建议采取过行动；也有研究测量消费者在当前情境下的采纳意愿，如刘亚男等（2022）测量的评论接受意愿，以及Jia、Zhao和Zhang（2026）测量的摘要采纳意愿。 / 5.2 采纳意愿的影响因素 / 信息有用性是影响信息采纳最直接的因素。Sussman和Siegal（2003）发现信息有用性在论据质量、来源可信度与信息采纳之间起中介作用；Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中发现，信息有用性会正向影响信息采纳；Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，摘要可信度会通过感知帮助程度影响消费者的采纳意愿。除有用性外，Filieri和McLeay（2014）发现信息的准确性、增值性、相关性、及时性以及产品排名都会影响游客对评论信息的采纳；Filieri（2015）发现消费者主要根据信息质量判断评论能否帮助自己识别商品的特点，即信息诊断性，而诊断性会进一步影响信息采纳。 /  /  / 6． 文献述评 / 综上所述，在线评论、信息采纳和感知有用性的研究基础比较扎实，概念、维度和量表都可以借鉴。评论的载体、结构、汇总评分和排列方式对消费者判断的影响，已在原始评论情境中得到较多检验，AI摘要情境中的相关研究还很少。AI评论摘要研究主要比较摘要的来源和平台引入摘要的效果，对呈现方式只比较过列表体和叙事体，摘要的分组依据和独立总览各自起什么作用还缺少检验。感知有用性和采纳意愿的研究也很少以整份AI摘要为对象。 / 基于此，本文以信息采纳模型为理论基础，以AI评论摘要的分组依据和有无独立总览为自变量，感知有用性为中介变量，消费者采纳意愿为因变量，通过2×2组间实验检验两个自变量的主效应和交互作用，以及感知有用性的中介作用，并以整体概括式作为补充对照组。 / 参考文献 / [1] 郝媛媛, 叶强, 李一军. 基于影评数据的在线评论有用性影响因素研究[J]. 管理科学学报, 2010, 13(8): DOI: 10.17705/1jais.00149. | 二、国内外研究现状概述 / 本文关心的是消费者怎样看待和使用AI评论摘要。按照“信息本身—信息的呈现—信息的采纳”的顺序，本部分先梳理在线评论的研究，再梳理AI评论摘要的研究，然后介绍信息采纳模型，并分别梳理模型中的感知有用性和采纳意愿，最后进行述评。 / 1 在线评论 / 1.1 在线评论的定义 / 在线评论源于口碑传播。传统口碑是消费者之间面对面的、非商业性的信息交流，互联网普及后，这种交流逐渐转移到线上。Hennig-Thurau等（2004）将网络口碑定义为潜在、现有或过去的消费者通过互联网发布的、关于产品或企业的任何正面或负面陈述，这些陈述可以被大量的个人和机构看到。在线评论是网络口碑中最常见、也最受研究关注的一种形式。Chen和Xie（2008）认为，在线消费者评论是用户根据个人使用经历发布的产品信息，可以看作营销沟通组合中的一种新要素；Mudambi和Schuff（2010）将在线评论定义为消费者在企业网站或第三方网站上发布的产品评价。 / 以上三种界定都包含三层含义：评论由消费者发布，内容来自其购买和使用经历，并在网络平台上公开展示。与传统口碑相比，在线评论的传播范围更广，一条评论可以被所有浏览商品页面的人看到；评论可以长期保存，消费者能够同时查看大量历史评论；发布者大多是陌生人，消费者无法像判断熟人意见那样判断其可靠性。相较于社交媒体上的分享内容，电商平台与点评网站的在线评论多围绕具体商品展开，通常由评分和文字组合而成，并由平台统一展示。由于评论数量庞大且来源分散，平台需要对这些评论进行进一步整理与呈现，AI摘要便是其中形式之一。 / 1.2 在线评论的维度 / 在线评论包含的信息较多，学者们一般把它拆成若干维度分别测量。Babić Rosario等（2016）对96项研究的1532个效应量进行元分析时，把口碑指标归纳为数量、效价、数量与效价的组合以及离散度四类。更早的Floyd等（2014）对26项实证研究进行元分析时，以评论效价和评论数量作为两个基本指标。以上种种指标均可归类为反映评论所包含的信息内容。 / 此外，信息质量研究将信息的表达方式视为信息质量的一个维度。Wang和Strong（1996）把信息质量分为内在、情境、表达和可获得性四类，其中表达质量既包括格式上的简洁和一致，也包括含义上的可解释和易理解，可获得性质量则指信息是否容易获取。 / 据此，本文把在线评论的维度分为信息维度和呈现维度两类。信息维度包括评论数量、评论效价、评论离散度、评论内容和评论者特征五个方面，其中前三个描述一组评论的整体情况，后两个描述单条评论的特点；呈现维度指评论向消费者展示的形式，也分为若干方面。 / 评论数量指某一商品获得的评论条数，通常用评论总数或一段时间内新增的评论数衡量，反映商品受关注的程度。评论效价指评论的正负倾向，常用平均评分、好评率或正负评论的比例衡量。Liu（2006）研究电影口碑时，分别用评论条数和正负评论的比例衡量数量和效价；Chevalier和Mayzlin（2006）则用平均星级以及一星、五星评论所占的比例衡量效价。Babić Rosario等（2016）指出，有些研究用“五星评论的条数”衡量效价，这类指标实际上同时包含了数量信息，应当单独作为“数量与效价的组合”来处理，否则会影响不同研究结论之间的比较。 / 评论离散度指不同消费者的评价之间的分歧程度，一般用评分的方差或标准差衡量。两件商品的评论数量和平均评分可能相同，但一件商品的评价比较一致，另一件商品好评和差评都很多，消费者从中得到的信息并不一样。 / 评论内容指评论文本本身的特征，是研究最多的维度，常用指标包括评论长度或深度、评论质量、可读性和情感倾向等。Mudambi和Schuff（2010）用评论字数衡量评论深度；Park等（2007）在实验中按论据是否客观、具体、有理由支撑来区分高质量评论和低质量评论；Korfiatis等（2012）用可读性指数衡量评论是否容易读懂；郝媛媛等（2010）通过文本挖掘提取评论的情感倾向和主客观表达等特征。 / 评论者特征指发布评论的消费者本身的信息，如评论者等级、历史评论数量、是否公开身份以及在平台上获得的认可等。这类信息一般显示在评论旁边，消费者会据此判断评论者是否可靠。 / 呈现维度与信息维度相互独立，同样的评论内容可以有不同的展示形式。在线评论研究中已有学者把呈现形式作为评论的一个特征，Xu等（2015）就把文字、图文和视频称为评论的不同呈现格式。呈现形式有的由评论者决定，如是否上传图片；有的由平台决定，如评分汇总、评论排序和评论摘要。由于本文研究的AI评论摘要属于后者，下一节对呈现维度单独展开梳理。 / 1.3 在线评论的呈现形式 / 呈现形式是呈现维度在平台上的具体表现。同样的评论内容，展示方式不同，消费者获取的信息和阅读顺序也会不同。根据平台实践和已有研究，本文从单条评论和多条评论两个层面梳理在线评论的呈现形式：前者关注单条评论的呈现载体和结构，后者关注平台对大量评论的汇总、排序和归纳方式。 / 单条评论的呈现首先体现在载体上。在线评论经历了从纯文字到图文结合、再到视频的变化，目前淘宝、京东等平台都允许消费者在评论中上传图片和视频。Xu等（2015）通过实验比较了文字评论、图文评论和视频评论三种呈现方式，发现消费者对视频评论的可信度和说服力评价更高，并且这种差异会随产品类型而变化。 / 单条评论的呈现还体现在结构上。多数平台的评论是消费者自由撰写的一段文字，也有平台要求按固定栏目填写，如分别填写优点和缺点，或对外观、性能等属性分别打分，这类评论称为结构化评论。刘亚男等（2022）通过组间实验比较了结构化评论和非结构化评论，发现对于体验型产品，结构化评论能提高评论深度和消费者的感知诊断性，对于搜索型产品则作用不明显。此外，国内电商平台普遍提供追加评论功能，消费者可以在初次评论一段时间后补充使用体验，使一条评论在时间上分成前后两部分。王长征等（2015）研究了消费者对追加评论有用性的感知，石文华等（2016）对初次评论和追加评论进行了比较，追加评论已经成为国内在线评论研究的一个专门方向。 / 多条评论层面的呈现形式主要有三类。一是评分汇总，平台通常在评论区顶部展示平均星级、评论总数和各星级的分布，消费者往往先看汇总评分，再看具体评论。Qiu等（2012）通过实验发现，当汇总评分与单条评论的倾向相矛盾时，消费者会降低对这条评论的可信度和诊断性判断，而且这种影响对正面评论更明显。这说明消费者会把汇总信息和单条评论放在一起理解。 / 二是评论的排序与组合。平台一般提供按时间、按有用性投票或按评分筛选等排序方式，消费者实际看到的只是排在前面的一部分评论。Purnawirawan等（2012）把消费者看到的多条评论作为一个“评论集合”来研究，发现集合中正负评论的比例和排列顺序都会影响消费者对整组评论的评价：正面或负面占多数的集合比正负各半的集合评价更高，把负面评论放在中间、首尾放正面评论的排列方式也能提高评价。 / 三是对评论内容进行归纳。一些平台从评论中提取高频词，生成“质量很好”“尺码偏大”等评论标签，并标注提及次数。刘景方等（2016）研究了用户评论标签摘要系统的有效性，这类系统按标签对评论进行归纳，帮助用户较快了解评论的主要观点。标签保留了评论中的具体属性信息，形式上是关键词的罗列。近年来出现的AI评论摘要更进一步，平台直接把多条评论的观点写成一段文字或若干条目，消费者不需要阅读原文就能了解评论的大致情况。AI评论摘要的相关研究放在第2节中梳理。 / 总体而言，在线评论呈现形式的研究对象已从单条评论扩展到由多条评论组成的评论集合，平台对评论的加工程度也不断提高，从展示原文、汇总评分、提取标签发展到直接生成摘要。加工程度越高，消费者获取的信息越依赖平台的组织方式。 / 在线评论呈现形式的研究覆盖了载体、结构、评分汇总、排序和标签等多种形式，研究对象多为单条评论或原始评论列表，对平台加工后形成的摘要关注较少。从信息维度看，AI评论摘要实际上是把一组评论的效价、离散度和评论内容中涉及的商品属性压缩成一份概括。从呈现维度看，结构化评论按优缺点或按属性组织单条评论，与AI评论摘要中按优缺点分组、按属性分项的做法组织逻辑相近，区别在于后者组织的是多条评论归纳后的内容。 / 据此，本文研究的在线评论限定为电商平台上的商品评论，研究对象是由多条评论归纳而成的AI评论摘要。在信息维度上，实验中各组商品的评论数量、平均评分以及摘要所依据的评价内容保持一致；在呈现维度上，本文研究的是AI评论摘要内部的信息组织方式。 / 2． AI评论摘要 / 本节先梳理AI评论摘要的定义和发展，再梳理消费者对AI评论摘要的反应，最后梳理摘要呈现方式的研究和平台做法，并由此引出本文研究的两个方面。 / 2.1 AI评论摘要的定义与发展 / “评论摘要”的概念最早来自计算机领域的观点摘要研究。Hu和Liu（2004）把评论摘要界定为一种基于商品特征的摘要：先找出消费者在评论中评价过的商品特征，再判断每个特征上的评价是正面还是负面，最后按特征汇总。Kim等（2011）在综述中采用了更宽的界定，把对大量观点生成简洁、易于理解的摘要的研究都归入观点摘要，并指出摘要可以是汇总后的情感评分，也可以是按属性或主题分解的结构化摘要，或是一段文字摘要。这一领域的定义着眼于摘要任务和输出形式。 / 围绕这一任务，摘要技术经历了几个阶段，摘要的输出形式也随之变化。Hu和Liu（2004）的摘要按商品特征逐项列出正面和负面评价的数量及例句；Liu等（2005）开发的Opinion Observer系统把不同商品在各属性上的优缺点做成可视化比较。之后的研究转向生成连贯的摘要文本，Ganesan等（2010）提出的Opinosis方法利用评论中反复出现的表达生成简短概括；Chu和Liu（2019）提出的MeanSum模型在没有人工摘要作为训练样本的情况下，也能生成多条评论的综合摘要。 / 大语言模型得到应用后，研究重点转向摘要是否忠实于原始评论。Hosking等（2024）先检索有代表性的评论片段，再由大模型据此生成摘要，使摘要内容能追溯到原文；Siledar等（2024）建立了观点摘要的评价数据集，从忠实性、属性覆盖和情感一致性等方面评价摘要质量。时至今日，按属性列出、按正负对比和连续文本这几种输出形式的呈现，在今天平台上的AI评论摘要中都能看到。 / 生成式AI进入电商平台以后，营销和信息管理领域开始把AI评论摘要作为一种新的平台信息来研究，界定的角度也随之变化。Wang和Wang（2025）以亚马逊2023年上线的功能为对象，将其描述为平台利用人工智能为消费者评论生成简洁摘要，并在过滤虚假或无用评论后置于评论区顶部，作用是从大量评论中提取关键信息。Jia、Zhao和Zhang（2026）认为AI评论摘要是生成式技术分析大量消费者评论后浓缩而成的简洁段落或要点，并把它看作在线评论的“代理”。Jia、Chi和Chi（2025）按生成来源把评论摘要分为AI生成和人工生成两类，说明“AI”一词限定的是摘要的生成主体。国内研究多使用“人工智能生成评论总结”或“AI评论总结”等说法。张鹏和刘春慧（2026）认为，人工智能生成评论总结把分散、碎片化的个体评论转化为聚合性结论，它与个体评论的本质区别在于算法对信息的筛选、重组与建构，具体包括三个方面：识别评论的效价，把模糊的情感表达转为正面、中性或负面的明确分类；抽取评论涉及的维度，如质量、物流和服务，并把分散的内容归类整合；按一定规则对效价信息和维度信息进行二次编排，形成有逻辑的总结框架。 / 比较上述界定，各研究在三点上基本一致：摘要的对象是同一商品或服务的多条评论，生成者是平台的算法，产出是比原始评论简短得多的概括内容。不同之处在于，计算机领域从任务和输出形式出发，营销和信息管理领域从来源和功能出发，多数默认摘要由生成式AI产生。Kim等（2011）和Jia、Zhao和Zhang（2026）提到摘要可以是评分、段落或要点等不同形式，张鹏和刘春慧（2026）把“二次编排”列为摘要的特征之一。 / 结合上述研究和平台实践，本文统一使用“AI评论摘要”一词，将其定义为平台利用人工智能技术，对某一商品或服务的多条用户评论进行归纳后形成、并展示给消费者的摘要内容，主要包括评论中的共同观点、涉及的商品属性和评论效价。与在线评论相比，AI评论摘要由平台生成，内容是对多条评论的整合。 / 2.2 消费者对AI评论摘要的反应 / 在消费者对AI评论摘要的反应方面，不少研究从摘要来源入手。Jia、Chi和Chi（2025）通过三项酒店预订情境实验发现，人工摘要在部分条件下更容易获得消费者信任，但在负面评价条件下，AI摘要和人工摘要带来的预订意愿没有显著差异。Chai等（2026）把措辞也考虑进来，发现当摘要用“多数”等文字形式表达概率时，消费者对AI摘要的反应反而比对人工摘要更积极，感知客观性和信任在其中起中介作用。Jia、Zhao和Zhang（2026）则不比较来源，而是调查了713名消费者对AI摘要本身的感知，发现透明性、可理解性和便利性会影响消费者对摘要可信度的判断。 / 另有研究利用平台数据考察摘要上线后的实际效果。Wang和Wang（2025）用亚马逊商品面板数据和双重差分方法，发现引入AI评论摘要后商品的购买行为指标有所改善；张鹏和古新成（2026）以酒店平台为对象，发现AI评论总结上线后，用户评论数量的增速下降了。前者考察的是消费者的购买行为，后者考察的是评论撰写行为。 / 总的来看，计算机领域的研究主要关注摘要的生成方法及其准确性；营销和信息管理领域的研究主要关注消费者对AI摘要的信任，以及平台引入摘要后消费者购买和评论行为的变化，对摘要内部怎样组织信息关注较少。 / 2.3 AI评论摘要的呈现模式 / 学术研究中对AI评论摘要呈现方式的讨论还不多。张鹏和刘春慧（2026）按信息组织逻辑把摘要的呈现结构分为列表体和叙事体两类：列表体用相互独立的条目逐项陈列商品属性和对应评价，如“优势：续航时间较长，且性价比很高；劣势：有用户反馈机身偏重”；叙事体则借助属性之间的关联，用连贯的段落叙述评价。他们通过眼动实验比较了两种呈现结构以及正面在前和负面在前两种效价顺序，发现呈现结构、效价顺序和产品类型会共同影响消费者对正面内容的视觉注意，并进一步影响购买意愿。 / 从平台实践看，AI评论摘要的组织方式主要有四种：App Store用一段连续文字概括评价；Naver Shopping按商品属性分条列出；美团按优点和缺点分栏；Tripadvisor先用一段话给出总体评价，再按属性列出细项。比较这四种做法，可以看到它们在两个方面不同。第一个方面是分组依据，即摘要内容按什么分组。评论信息由商品属性和评论效价两种成分构成，Hu和Liu（2004）的评论摘要就是按商品属性汇总正负评价，优缺点分栏或按属性打分。摘要可以按属性分组，可以按效价分组，也可以不分组。第二个方面是有无独立总览，即分组内容之前是否另有一段总体评价。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。 / 用这两个方面可以描述上述四种做法：App Store不分组，整段文字本身就是对评价的总体概括，本文称为整体概括式；Naver Shopping按属性分组、没有独立总览，称为属性分项式；美团按效价分组、没有独立总览，称为优缺点分组式；Tripadvisor有独立总览，后面的细项按属性分组，称为总分结合式。总分结合式后面的细项也可以按效价分组，本文据此把它分为属性型和优缺点型两种。与张鹏和刘春慧（2026）的划分相比，他们的叙事体对应本文的整体概括式，列表体在本文中按分组依据分成属性分项式和优缺点分组式，总分结合式是本文增加的一类。 / 本文从分组依据和有无独立总览两个方面研究呈现模式，因为这两个方面决定了消费者打开摘要后先看到什么、按什么顺序找信息，也是各平台做法差别最大的地方。实验把两个方面交叉：分组依据取按属性和按优缺点两个水平，独立总览取有和无两个水平，得到属性分项式、优缺点分组式以及属性型和优缺点型两种总分结合式，共四组。整体概括式不分组作为补充对照组，用来比较分条组织和连续段落的差别。 / 3． 信息采纳模型 / 本文以信息采纳模型为理论基础。本节介绍模型的提出和后续扩展，并说明本文怎样使用这一模型。 / 3.1 模型的提出 / 信息采纳模型由Sussman和Siegal（2003）提出，用来解释个体在接收到信息后为什么会采纳这些信息。该模型结合了技术接受模型（Davis，1989）和精细加工可能性模型（Petty和Cacioppo，1986）。精细加工可能性模型认为，个体处理信息有中心路径和边缘路径两种方式，前者主要依据信息内容本身进行判断，后者主要依据信息来源等外部线索进行判断。信息采纳模型据此把论据质量和来源可信度作为前因变量，分别对应中心路径和边缘路径；同时借鉴技术接受模型中感知有用性影响使用意向的思路，把信息有用性作为中介变量，把信息采纳作为结果变量。Sussman和Siegal（2003）以企业员工收到的建议邮件为对象进行检验，发现论据质量和来源可信度会通过信息有用性影响员工对建议的采纳，员工的专业知识和涉入程度会调节这一过程。 / 3.2 模型的扩展与应用 / 此后，学者们在不同情境中对该模型进行了检验和扩展。Bhattacherjee和Sanford（2006）把精细加工可能性模型用于信息技术接受研究，用论据质量和来源可信度解释用户的感知有用性和态度，并发现用户的专业知识和工作相关性会调节这两条路径的作用。Zhang和Watts（2008）以两个在线社区为对象，发现论据质量和来源可信度都会影响成员对社区信息的采纳，当新信息与已有认知不一致或成员带着明确目的搜索时，成员对来源可信度的依赖会减弱。Cheung等（2008）把模型用于在线消费者社区，发现论据质量中的相关性和全面性对信息有用性的影响较大，而来源可信度的影响不显著。Erkan和Evans（2016）在社交媒体情境中提出扩展的信息采纳模型，加入了信息需求和对信息的态度两个变量，并把购买意愿作为信息采纳之后的结果。 / 从已有研究看，信息采纳模型已经从组织内部的邮件沟通扩展到在线社区、在线评论和社交媒体等情境，“信息有用性影响信息采纳”这一核心路径得到了反复验证。这些研究的前因变量主要是论据质量、来源可信度等内容与来源特征，信息的呈现形式很少被考虑。因此，本文以信息采纳模型为理论基础，把AI评论摘要的呈现模式作为影响消费者处理信息的前因，保留“感知有用性—采纳意愿”这一核心路径。 / 4． 感知有用性 / 4.1 感知有用性的定义 / 感知有用性最早来自技术接受模型。Davis（1989）将其定义为个体认为使用某一特定系统能够提高其工作绩效的程度。Sussman和Siegal（2003）把这一概念用到信息采纳研究中，提出了信息有用性，指个体认为使用某条信息能够帮助自己更好地完成任务的程度。在在线评论研究中，学者们常用“评论有用性”这一概念，Mudambi和Schuff（2010）将有用的评论定义为能够帮助消费者完成购买决策的评论。三个概念的适用对象依次为信息系统、一般信息和在线评论，核心含义一致，均指个体对某一对象能否帮助自己完成任务的判断。本文的研究对象为AI评论摘要，统一使用“感知有用性”这一表述，文中引用的信息有用性和评论有用性研究均按这一含义理解。 / 4.2 感知有用性的测量 / 已有研究测量有用性主要有两种方式。第一种是利用平台上的“有帮助”投票数或投票比例，如Mudambi和Schuff（2010）、Korfiatis等（2012）的研究，这类数据反映的是其他用户对单条评论的评价。第二种是用问卷测量消费者自己感知到的有用程度。Davis（1989）开发的感知有用性量表包括提高工作效率、提高工作绩效和更容易完成工作等题项；Cheung等（2008）结合在线评论情境，从“有价值的”“有信息量的”“有帮助的”三个方面测量信息有用性。多数研究把感知有用性作为单维变量处理。 / 4.3 感知有用性的影响因素 / 在有用性的影响因素中，研究最多的是评论内容本身。Mudambi和Schuff（2010）发现评论深度和评分极端程度会影响评论有用性，且评论深度对搜索型产品的作用更强。Korfiatis等（2012）发现，可读性对“有帮助”投票比例的影响比评论长度更大。郝媛媛等（2010）用国内影评数据得出的结论是，积极的情感倾向、较高的正负情感混杂度和较长的平均句长都会提高评论有用性。Cheung等（2008）则从论据质量的角度，发现相关性和全面性的影响最大。 / 也有研究关注信息来源和评论者特征的作用。Sussman和Siegal（2003）发现来源可信度会影响信息有用性；Pan和Zhang（2011）发现评论者在文字中表现出的创新性与评论有用性呈倒U型关系；Ghose和Ipeirotis（2011）把文本特征和评论者信息放在一起分析，发现主观性、可读性、拼写错误和评论者的历史信息都有影响；殷国鹏（2012）基于豆瓣网数据，发现评论与平均星级的偏差、评论者的社会特征也会起作用。 / 从呈现方式解释有用性的研究相对较少。刘亚男等（2022）发现，对于体验型产品，结构化呈现的评论能提高感知诊断性和感知有用性；Jia、Zhao和Zhang（2026）发现，AI摘要的可理解性和便利性会提高消费者对摘要的信任，并提高其感知帮助程度。 /  /  / 5 采纳意愿 / 5.1 采纳意愿的定义与测量 / 信息采纳指个体有目的地使用信息的过程（Sussman和Siegal，2003）。在在线评论情境中，Cheung等（2008）把信息采纳理解为消费者接受评论中的观点，并据此作出购买相关的决策。Erkan和Evans（2016）进一步区分了信息采纳和购买意愿，认为消费者先采纳信息，再形成购买意愿。在测量上，部分研究测量的是消费者已经发生的采纳行为，如Cheung等（2008）的题项询问消费者是否同意评论观点、是否按照评论建议采取过行动；也有研究测量消费者在当前情境下的采纳意愿，如刘亚男等（2022）测量的评论接受意愿，以及Jia、Zhao和Zhang（2026）测量的摘要采纳意愿。 / 5.2 采纳意愿的影响因素 / 信息有用性是影响信息采纳最直接的因素。Sussman和Siegal（2003）发现信息有用性在论据质量、来源可信度与信息采纳之间起中介作用；Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中发现，信息有用性会正向影响信息采纳；Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，摘要可信度会通过感知帮助程度影响消费者的采纳意愿。除有用性外，Filieri和McLeay（2014）发现信息的准确性、增值性、相关性、及时性以及产品排名都会影响游客对评论信息的采纳；Filieri（2015）发现消费者主要根据信息质量判断评论能否帮助自己识别商品的特点，即信息诊断性，而诊断性会进一步影响信息采纳。 /  /  / 6． 文献述评 / 综上所述，在线评论、信息采纳和感知有用性的研究基础比较扎实，概念、维度和量表都可以借鉴。评论的载体、结构、汇总评分和排列方式对消费者判断的影响，已在原始评论情境中得到较多检验，AI摘要情境中的相关研究还很少。AI评论摘要研究主要比较摘要的来源和平台引入摘要的效果，对呈现方式只比较过列表体和叙事体，摘要的分组依据和独立总览各自起什么作用还缺少检验。感知有用性和采纳意愿的研究也很少以整份AI摘要为对象。 / 基于此，本文以信息采纳模型为理论基础，以AI评论摘要的分组依据和有无独立总览为自变量，感知有用性为中介变量，消费者采纳意愿为因变量，通过2×2组间实验检验两个自变量的主效应和交互作用，以及感知有用性的中介作用，并以整体概括式作为补充对照组。 / 参考文献 / [1] 郝媛媛, 叶强, 李一军. 基于影评数据的在线评论有用性影响因素研究[J]. 管理科学学报, 2010, 13(8):    | 四、拟采用的研究思路（方法、技术路线、可行性论证等） / 1． 研究方法 / （1）文献研究法。通过中国知网、Web of Science等数据库检索在线评论、AI评论摘要、信息采纳和感知有用性等方面的中英文文献，梳理各变量的定义、维度和测量方式，为构建研究模型、提出研究假设和设计问卷提供依据。 / （2）平台调查法。收集国内外平台关于AI评论摘要的官方介绍、界面示例和第三方截图，按照统一的规则记录摘要的组织方式，并据此归纳平台常见的摘要组织方式。后续将请一名同学与笔者分别独立编码，对不一致的地方进行讨论，并计算编码一致性。 / （3）情境实验法。采用2（分组依据：按属性、按优缺点）×2（独立总览：有、无）组间实验设计，另设整体概括式作为补充对照组，共五组。被试被随机分配到其中一组，每名被试只阅读一种摘要。问卷先展示购物情境和模拟商品页面，再测量被试的感知有用性和采纳意愿。各组的商品信息和评价内容相同，只改变摘要的组织方式。 / （4）统计分析法。使用SPSS及PROCESS插件进行数据分析。先进行描述性统计、信效度检验和操纵检验；再对四个实验组的数据进行双因素方差分析，检验分组依据和独立总览对感知有用性和采纳意愿的主效应及交互作用。中介效应采用Hayes（2018）的PROCESS程序，用Bootstrap法检验感知有用性的间接效应；交互作用显著时，进一步用模型7检验有调节的中介效应。整体概括式对照组与其余四组的比较采用单因素方差分析和事后多重比较，作为探索性分析。 / 2． 研究方案 / （1）了解AI评论摘要的应用现状，确定研究问题； / （2）以研究问题为导向，梳理在线评论、AI评论摘要、信息采纳模型、感知有用性和采纳意愿的相关文献，界定各变量的概念和测量方式； / （3）通过平台调研归纳摘要的组织方式，提炼分组依据和独立总览两个方面，结合文献提出研究假设，构建研究模型； / （4）制作实验材料，设计问卷，开展预实验和正式实验； / （5）进行数据分析，检验研究假设； / （6）总结研究结论，提出平台设计建议，说明研究局限。 / 3． 技术路线 / 本文主要分以下五个阶段开展研究工作，技术路线见图2： / 第一阶段，基础理论：阐述研究背景、目的和意义，梳理在线评论、AI评论摘要、信息采纳模型、感知有用性和采纳意愿的相关文献，形成文献综述。 / 本文以AI评论摘要的分组依据和有无独立总览为自变量。分组依据包括按属性分组和按优缺点分组两个水平，独立总览包括有和无两个水平，两者交叉形成四个实验组。感知有用性为中介变量，消费者采纳意愿为因变量。整体概括式作为补充对照组，不进入研究模型。各变量的定义见本报告第二部分，研究模型如图3所示。 /  / 图3  研究模型 / 4.2 分组依据与感知有用性、采纳意愿 / 消费者阅读AI评论摘要，是为了了解商品在各方面的表现，并判断商品是否适合自己。这个过程包括两项工作：一是在摘要中找到自己关心的属性的评价，二是把各方面的评价合成对商品的整体判断。本文把完成这两项工作所需的阅读和思考分别称为查找成本和整合成本。已有研究表明，信息的组织方式会改变消费者处理信息的难易程度。Bettman和Kakkar（1977）发现，产品信息按品牌组织还是按属性组织，消费者就相应地按品牌或按属性获取信息；Payne（1976）发现，备选方案和属性增多时，消费者会改用更简化的决策策略；Lee和Lee（2004）以及Lurie（2004）也发现，信息的数量和结构会影响消费者的加工负担和决策质量。在评论情境中，刘亚男等（2022）发现，对于体验型产品，按栏目填写的结构化评论能提高消费者的感知有用性和评论接受意愿。 / 分组依据主要影响查找成本。本文实验选用的运动鞋需要从舒适性、透气性和耐磨性等多个属性进行评价，消费者往往带着具体的关注点阅读摘要，比如鞋子是否透气、是否耐穿。按属性分组时，同一属性的正负评价集中在一处，消费者可以直接找到关心的属性；按优缺点分组时，同一属性的评价可能分别出现在“优点”和“缺点”两栏，消费者要在两栏之间对照，才能了解某一属性的完整情况。Bettman和Kakkar（1977）的研究也说明，信息按属性组织时，消费者更容易按属性逐项比较。消费者花较少的工夫就能找到所需信息时，会认为摘要更有帮助，也更愿意采用其中的评价。据此提出以下假设： / H1：相较于按优缺点分组，按多属性分组的AI评论摘要下，消费者的感知有用性（H1a）和采纳意愿（H1b）更高。 / 4.3 独立总览与感知有用性、采纳意愿 / 独立总览主要影响整合成本。没有总览时，消费者需要读完各组内容，自己判断商品整体是好是坏；有总览时，摘要开头已经给出整体评价，消费者可以先了解大致情况，再按需要查看细项。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。总览会增加篇幅，不过它放在开头，消费者可以先读总览，再决定是否继续阅读细项。总览降低了形成整体判断的难度，消费者会认为摘要更有用，也更愿意采用摘要中的信息。据此提出以下假设： / H2：相较于无独立总览，有独立总览的AI评论摘要下，消费者的感知有用性（H2a）和采纳意愿（H2b）更高。 / 4.4 分组依据与独立总览的交互作用 / 两种分组方式对整合的帮助不同。按优缺点分组时，正面和负面评价已经分开，消费者可以直接比较优点和缺点，权衡利弊比较容易，整体判断有一部分已经由分组完成；按属性分组时，各属性的评价分散在不同条目中，消费者要逐项比较后再形成整体判断，整合成本较高。因此，在按属性分组的摘要中，独立总览补上的正是这类摘要缺少的整体判断，作用应当更明显；在按优缺点分组的摘要中，总览和分组本身的作用有一部分重叠，增加的帮助相对较小。据此提出以下假设： / H3：分组依据与独立总览存在交互作用，独立总览对感知有用性（H3a）和采纳意愿（H3b）的正向影响在按属性分组时更强。 / 4.5 感知有用性与消费者采纳意愿 / 信息采纳模型认为，信息有用性是影响信息采纳的直接因素（Sussman和Siegal，2003）。Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中证实了信息有用性对信息采纳的正向影响，Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，消费者感知到的帮助程度会正向影响其采纳意愿。当消费者认为摘要能够帮助自己了解和评价商品时，会更愿意在判断中使用摘要中的信息。据此提出以下假设： / H4：感知有用性正向影响消费者对AI评论摘要的采纳意愿。 / 4.6 感知有用性的中介作用 / 结合以上分析，分组依据和独立总览会影响消费者对摘要有用性的判断，而有用性判断又会影响消费者的采纳意愿。因此，两个方面对采纳意愿的影响可能有一部分是通过感知有用性实现的。据此提出以下假设： / H5：感知有用性在分组依据（H5a）和独立总览（H5b）对消费者采纳意愿的影响中起中介作用。 / 5． 实验设计 / 5.1 平台摘要组织方式的归纳 / 前期调研共整理了94条国内外平台及业务入口记录，其中国内33条、海外61条。其中有官方或平台自身资料的28条，主要依靠第三方资料的17条，其余49条的功能情况还需要进一步核实；同时归档了涉及20条记录的43张界面截图。本文按照分组依据和有无独立总览对这些记录进行归类，得到四种组织方式，具体见表2。 / 表2  平台AI评论摘要的四种组织方式 / 归类时先看页面有无独立总览，有且其后列有分项内容的，归为总分结合式；没有的再看分组依据，不分组的归为整体概括式，按商品属性分组的归为属性分项式，按优点和缺点分组的归为优缺点分组式。摘要的位置、默认展示范围、展开方式和原始评论入口另外记录。 / 5.2 实验分组与实验材料 / 实验采用2（分组依据：按属性、按优缺点）×2（独立总览：有、无）组间设计，形成四个实验组：A组为属性分项式，B组为优缺点分组式，C组为属性型总分结合式，D组为优缺点型总分结合式。另设E组为整体概括式，作为补充对照组。被试被随机分配到其中一组，每人只阅读一种摘要，以免被试比较不同页面后猜出研究目的。五组摘要来自同一份评论底稿，包含相同的商品属性、评价内容、效价和表达强度，只改变内容的组织方式。 / 底稿同时包含正面和负面评价。实际平台的AI评论摘要通常会同时概括优点和不足，同时提到正反两方面的信息也更可信（Eisend，2006；Jensen等，2013）；而且只有正面内容时，优缺点分组式无法成立。 / 各组摘要中正负评价的条数比例相同，并统一按先正后负的顺序排列。C组和D组的总览段落完全相同，后面的细项分别与A组和B组相同，因此C组与A组、D组与B组之间只差总览这一段。E组用一段连续文字写出底稿中的全部评价。制作材料时将记录各组字数，除总览外，各组篇幅尽量接近。各组的具体设计见表3。 / 表3  各实验组的摘要设计 / 实验情境选择日常运动鞋。问卷首先请被试设想自己准备购买一双日常穿着的运动鞋，正在浏览商品页面；然后展示带有AI评论摘要的模拟商品页面图片；最后请被试回答问卷题目。 / 五组页面使用相同的虚构品牌、商品图片、名称、价格、评分和评论数量，摘要的位置、卡片大小、字体、字号、颜色和“AI生成”标识也保持一致。摘要内容涵盖舒适性、透气性和耐磨性等属性，并全部展开显示。摘要中的比例信息统一用“多数用户”“少数用户”等文字表述；页面只展示AI评论摘要，没有原始评论和跳转入口。 / 这样测得的感知有用性只反映摘要本身；如果提供原始评论，被试是否翻看、看多少会因人而异。去掉原始评论会降低实验情境的真实感；另外，E组为连贯段落，其余四组为分条内容，E组与其他组的差别同时包含文字结构上的差别，比较结果只作为补充参考。这两点将在论文的研究局限中说明。 / 正式实验前，先进行少量认知访谈，了解被试对页面和题目的理解；再开展小规模预实验，检查图片是否清晰、各组摘要是否容易区分、各组内容是否被认为基本一致，并根据结果修改材料和问卷。 / 6. 变量测量 / 实施可行性 / 前期已经完成文献梳理和平台资料的初步整理，五组实验材料可以用同一个商品页面模板制作，在线问期卷平台也可以实现随机分组。样本量用G*Power估算：按中等效应量（f＝0.25）、0.05的显著性水平和0.8的统计功效，2×2双因素方差分析的主效应和交互效应共需约128份有效问卷；加入对照组后进行五组单因素比较，共需约200份，即每组约40份。考虑到会有一部分无效问卷，计划每组回收约50份，共约250份，最终样本量会根据预实验结果再作调整。 （2）平台调查法。收集国内外平台关于AI评论摘要的官方介绍、界面示例和第三方截图，按照统一的规则记录摘要的组织方式，并据此归纳平台常见的摘要组织方式。后续将请一名同学与笔者分别独立编码，对不一致的地方进行讨论，并计算编码一致性。 / （3）情境实验法。采用2（分组依据：按属性、按优缺点）×2（独立总览：有、无）组间实验设计，另设整体概括式作为补充对照组，共五组。被试被随机分配到其中一组，每名被试只阅读一种摘要。问卷先展示购物情境和模拟商品页面，再测量被试的感知有用性和采纳意愿。各组的商品信息和评价内容相同，只改变摘要的组织方式。 / 分组依据主要影响查找成本。本文实验选用的运动鞋需要从舒适性、透气性和耐磨性等多个属性进行评价，消费者往往带着具体的关注点阅读摘要，比如鞋子是否透气、是否耐穿。按属性分组时，同一属性的正负评价集中在一处，消费者可以直接找到关心的属性；按优缺点分组时，同一属性的评价可能分别出现在“优点”和“缺点”两栏，消费者要在两栏之间对照，才能了解某一属性的完整情况。Bettman和Kakkar（1977）的研究也说明，信息按属性组织时，消费者更容易按属性逐项比较。消费者花较少的工夫就能找到所需信息时，会认为摘要更有帮助，也更愿意采用其中的评价。据此提出以下假设： / H1：相较于按优缺点分组，按多属性分组的AI评论摘要下，消费者的感知有用性（H1a）和采纳意愿（H1b）更高。 / 4.3 独立总览与感知有用性、采纳意愿 / 独立总览主要影响整合成本。没有总览时，消费者需要读完各组内容，自己判断商品整体是好是坏；有总览时，摘要开头已经给出整体评价，消费者可以先了解大致情况，再按需要查看细项。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。总览会增加篇幅，不过它放在开头，消费者可以先读总览，再决定是否继续阅读细项。总览降低了形成整体判断的难度，消费者会认为摘要更有用，也更愿意采用摘要中的信息。据此提出以下假设： / H2：相较于无独立总览，有独立总览的AI评论摘要下，消费者的感知有用性（H2a）和采纳意愿（H2b）更高。 / 4.4 分组依据与独立总览的交互作用 / 两种分组方式对整合的帮助不同。按优缺点分组时，正面和负面评价已经分开，消费者可以直接比较优点和缺点，权衡利弊比较容易，整体判断有一部分已经由分组完成；按属性分组时，各属性的评价分散在不同条目中，消费者要逐项比较后再形成整体判断，整合成本较高。因此，在按属性分组的摘要中，独立总览补上的正是这类摘要缺少的整体判断，作用应当更明显；在按优缺点分组的摘要中，总览和分组本身的作用有一部分重叠，增加的帮助相对较小。据此提出以下假设： / H3：分组依据与独立总览存在交互作用，独立总览对感知有用性（H3a）和采纳意愿（H3b）的正向影响在按属性分组时更强。 / 4.5 感知有用性与消费者采纳意愿 / 信息采纳模型认为，信息有用性是影响信息采纳的直接因素（Sussman和Siegal，2003）。Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中证实了信息有用性对信息采纳的正向影响，Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，消费者感知到的帮助程度会正向影响其采纳意愿。当消费者认为摘要能够帮助自己了解和评价商品时，会更愿意在判断中使用摘要中的信息。据此提出以下假设： / H4：感知有用性正向影响消费者对AI评论摘要的采纳意愿。 / 4.6 感知有用性的中介作用 / 结合以上分析，分组依据和独立总览会影响消费者对摘要有用性的判断，而有用性判断又会影响消费者的采纳意愿。因此，两个方面对采纳意愿的影响可能有一部分是通过感知有用性实现的。据此提出以下假设： / H5：感知有用性在分组依据（H5a）和独立总览（H5b）对消费者采纳意愿的影响中起中介作用。 / 5． 底稿同时包含正面和负面评价。实际平台的AI评论摘要通常会同时概括优点和不足，同时提到正反两方面的信息也更可信（Eisend，2006；Jensen等，2013）；而且只有正面内容时，优缺点分组式无法成立。 / 各组摘要中正负评价的条数比例相同，并统一按先正后负的顺序排列。C组和D组的总览段落完全相同，后面的细项分别与A组和B组相同，因此C组与A组、D组与B组之间只差总览这一段。E组用一段连续文字写出底稿中的全部评价。制作材料时将记录各组字数，除总览外，各组篇幅尽量接近。各组的具体设计见表3。 / 表3  各实验组的摘要设计 / 实验情境选择日常运动鞋。问卷首先请被试设想自己准备购买一双日常穿着的运动鞋，正在浏览商品页面；然后展示带有AI评论摘要的模拟商品页面图片；最后请被试回答问卷题目。 / 五组页面使用相同的虚构品牌、商品图片、名称、价格、评分和评论数量，摘要的位置、卡片大小、字体、字号、颜色和“AI生成”标识也保持一致。摘要内容涵盖舒适性、透气性和耐磨性等属性，并全部展开显示。摘要中的比例信息统一用“多数用户”“少数用户”等文字表述；页面只展示AI评论摘要，没有原始评论和跳转入口。 / 这样测得的感知有用性只反映摘要本身；如果提供原始评论，被试是否翻看、看多少会因人而异。去掉原始评论会降低实验情境的真实感；另外，E组为连贯段落，其余四组为分条内容，E组与其他组的差别同时包含文字结构上的差别，比较结果只作为补充参考。这两点将在论文的研究局限中说明。 / （2）平台调查法。收集国内外平台关于AI评论摘要的官方介绍、界面示例和第三方截图，按照统一的规则记录摘要的组织方式，并据此归纳平台常见的摘要组织方式。后续将请一名同学与笔者分别独立编码，对不一致的地方进行讨论，并计算编码一致性。 / （3）情境实验法。采用2（分组依据：按属性、按优缺点）×2（独立总览：有、无）组间实验设计，另设整体概括式作为补充对照组，共五组。被试被随机分配到其中一组，每名被试只阅读一种摘要。问卷先展示购物情境和模拟商品页面，再测量被试的感知有用性和采纳意愿。各组的商品信息和评价内容相同，只改变摘要的组织方式。 / （4）统计分析法。使用SPSS及PROCESS插件进行数据分析。先进行描述性统计、信效度检验和操纵检验；再对四个实验组的数据进行双因素方差分析，检验分组依据和独立总览对感知有用性和采纳意愿的主效应及交互作用。中介效应采用Hayes（2018）的PROCESS程序，用Bootstrap法检验感知有用性的间接效应；交互作用显著时，进一步用模型7检验有调节的中介效应。整体概括式对照组与其余四组的比较采用单因素方差分析和事后多重比较，作为探索性分析。 （5）进行数据分析，检验研究假设； / （6）总结研究结论，提出平台设计建议，说明研究局限。 / 3． 技术路线 / 本文主要分以下五个阶段开展研究工作，技术路线见图2： / 第一阶段，基础理论：阐述研究背景、目的和意义，梳理在线评论、AI评论摘要、信息采纳模型、感知有用性和采纳意愿的相关文献，形成文献综述。 / / H2：相较于无独立总览，有独立总览的AI评论摘要下，消费者的感知有用性（H2a）和采纳意愿（H2b）更高。 / 4.4 分组依据与独立总览的交互作用 / 两种分组方式对整合的帮助不同。按优缺点分组时，正面和负面评价已经分开，消费者可以直接比较优点和缺点，权衡利弊比较容易，整体判断有一部分已经由分组完成；按属性分组时，各属性的评价分散在不同条目中，消费者要逐项比较后再形成整体判断，整合成本较高。因此，在按属性分组的摘要中，独立总览补上的正是这类摘要缺少的整体判断，作用应当更明显；在按优缺点分组的摘要中，总览和分组本身的作用有一部分重叠，增加的帮助相对较小。据此提出以下假设： / H3：分组依据与独立总览存在交互作用，独立总览对感知有用性（H3a）和采纳意愿（H3b）的正向影响在按属性分组时更强。 / 4.5 感知有用性与消费者采纳意愿 / 信息采纳模型认为，信息有用性是影响信息采纳的直接因素（Sussman和Siegal，2003）。Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中证实了信息有用性对信息采纳的正向影响，Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，消费者感知到的帮助程度会正向影响其采纳意愿。当消费者认为摘要能够帮助自己了解和评价商品时，会更愿意在判断中使用摘要中的信息。据此提出以下假设： / H4：感知有用性正向影响消费者对AI评论摘要的采纳意愿。 / 4.6 感知有用性的中介作用 / 结合以上分析，分组依据和独立总览会影响消费者对摘要有用性的判断，而有用性判断又会影响消费者的采纳意愿。因此，两个方面对采纳意愿的影响可能有一部分是通过感知有用性实现的。据此提出以下假设： / H5：感知有用性在分组依据（H5a）和独立总览（H5b）对消费者采纳意愿的影响中起中介作用。 / 5． 底稿同时包含正面和负面评价。实际平台的AI评论摘要通常会同时概括优点和不足，同时提到正反两方面的信息也更可信（Eisend，2006；Jensen等，2013）；而且只有正面内容时，优缺点分组式无法成立。 / 各组摘要中正负评价的条数比例相同，并统一按先正后负的顺序排列。C组和D组的总览段落完全相同，后面的细项分别与A组和B组相同，因此C组与A组、D组与B组之间只差总览这一段。E组用一段连续文字写出底稿中的全部评价。制作材料时将记录各组字数，除总览外，各组篇幅尽量接近。各组的具体设计见表3。 / 表3  各实验组的摘要设计 / 实验情境选择日常运动鞋。问卷首先请被试设想自己准备购买一双日常穿着的运动鞋，正在浏览商品页面；然后展示带有AI评论摘要的模拟商品页面图片；最后请被试回答问卷题目。 / 这样测得的感知有用性只反映摘要本身；如果提供原始评论，被试是否翻看、看多少会因人而异。去掉原始评论会降低实验情境的真实感；另外，E组为连贯段落，其余四组为分条内容，E组与其他组的差别同时包含文字结构上的差别，比较结果只作为补充参考。这两点将在论文的研究局限中说明。 / 正式实验前，先进行少量认知访谈，了解被试对页面和题目的理解；再开展小规模预实验，检查图片是否清晰、各组摘要是否容易区分、各组内容是否被认为基本一致，并根据结果修改材料和问卷。 / 6. 变量测量 / （5）进行数据分析，检验研究假设； / （6）总结研究结论，提出平台设计建议，说明研究局限。 / 3． 技术路线 / 本文主要分以下五个阶段开展研究工作，技术路线见图2： / 第一阶段，基础理论：阐述研究背景、目的和意义，梳理在线评论、AI评论摘要、信息采纳模型、感知有用性和采纳意愿的相关文献，形成文献综述。 / 本文以AI评论摘要的分组依据和有无独立总览为自变量。分组依据包括按属性分组和按优缺点分组两个水平，独立总览包括有和无两个水平，两者交叉形成四个实验组。感知有用性为中介变量，消费者采纳意愿为因变量。整体概括式作为补充对照组，不进入研究模型。各变量的定义见本报告第二部分，研究模型如图3所示。 /  / 图3  研究模型 / 4.2 分组依据与感知有用性、采纳意愿 / 消费者阅读AI评论摘要，是为了了解商品在各方面的表现，并判断商品是否适合自己。这个过程包括两项工作：一是在摘要中找到自己关心的属性的评价，二是把各方面的评价合成对商品的整体判断。本文把完成这两项工作所需的阅读和思考分别称为查找成本和整合成本。已有研究表明，信息的组织方式会改变消费者处理信息的难易程度。Bettman和Kakkar（1977）发现，产品信息按品牌组织还是按属性组织，消费者就相应地按品牌或按属性获取信息；Payne（1976）发现，备选方案和属性增多时，消费者会改用更简化的决策策略；Lee和Lee（2004）以及Lurie（2004）也发现，信息的数量和结构会影响消费者的加工负担和决策质量。在评论情境中，刘亚男等（2022）发现，对于体验型产品，按栏目填写的结构化评论能提高消费者的感知有用性和评论接受意愿。 / 分组依据主要影响查找成本。本文实验选用的运动鞋需要从舒适性、透气性和耐磨性等多个属性进行评价，消费者往往带着具体的关注点阅读摘要，比如鞋子是否透气、是否耐穿。按属性分组时，同一属性的正负评价集中在一处，消费者可以直接找到关心的属性；按优缺点分组时，同一属性的评价可能分别出现在“优点”和“缺点”两栏，消费者要在两栏之间对照，才能了解某一属性的完整情况。Bettman和Kakkar（1977）的研究也说明，信息按属性组织时，消费者更容易按属性逐项比较。消费者花较少的工夫就能找到所需信息时，会认为摘要更有帮助，也更愿意采用其中的评价。据此提出以下假设： / H1：相较于按优缺点分组，按多属性分组的AI评论摘要下，消费者的感知有用性（H1a）和采纳意愿（H1b）更高。 / 4.3 独立总览与感知有用性、采纳意愿 / 独立总览主要影响整合成本。没有总览时，消费者需要读完各组内容，自己判断商品整体是好是坏；有总览时，摘要开头已经给出整体评价，消费者可以先了解大致情况，再按需要查看细项。Kim等（2011）认为，总体层面的摘要和按主题分解的摘要提供的是不同层次的理解，两者可以相互补充。总览会增加篇幅，不过它放在开头，消费者可以先读总览，再决定是否继续阅读细项。总览降低了形成整体判断的难度，消费者会认为摘要更有用，也更愿意采用摘要中的信息。据此提出以下假设： / H2：相较于无独立总览，有独立总览的AI评论摘要下，消费者的感知有用性（H2a）和采纳意愿（H2b）更高。 / 4.4 分组依据与独立总览的交互作用 / 两种分组方式对整合的帮助不同。按优缺点分组时，正面和负面评价已经分开，消费者可以直接比较优点和缺点，权衡利弊比较容易，整体判断有一部分已经由分组完成；按属性分组时，各属性的评价分散在不同条目中，消费者要逐项比较后再形成整体判断，整合成本较高。因此，在按属性分组的摘要中，独立总览补上的正是这类摘要缺少的整体判断，作用应当更明显；在按优缺点分组的摘要中，总览和分组本身的作用有一部分重叠，增加的帮助相对较小。据此提出以下假设： / H3：分组依据与独立总览存在交互作用，独立总览对感知有用性（H3a）和采纳意愿（H3b）的正向影响在按属性分组时更强。 / 4.5 感知有用性与消费者采纳意愿 / 信息采纳模型认为，信息有用性是影响信息采纳的直接因素（Sussman和Siegal，2003）。Cheung等（2008）和Erkan和Evans（2016）分别在在线消费者社区和社交媒体情境中证实了信息有用性对信息采纳的正向影响，Jia、Zhao和Zhang（2026）在AI评论摘要情境中也发现，消费者感知到的帮助程度会正向影响其采纳意愿。当消费者认为摘要能够帮助自己了解和评价商品时，会更愿意在判断中使用摘要中的信息。据此提出以下假设： / H4：感知有用性正向影响消费者对AI评论摘要的采纳意愿。 / 4.6 感知有用性的中介作用 / 结合以上分析，分组依据和独立总览会影响消费者对摘要有用性的判断，而有用性判断又会影响消费者的采纳意愿。因此，两个方面对采纳意愿的影响可能有一部分是通过感知有用性实现的。据此提出以下假设： / H5：感知有用性在分组依据（H5a）和独立总览（H5b）对消费者采纳意愿的影响中起中介作用。 / 5． 实验设计 / 5.1 平台摘要组织方式的归纳 / 前期调研共整理了94条国内外平台及业务入口记录，其中国内33条、海外61条。其中有官方或平台自身资料的28条，主要依靠第三方资料的17条，其余49条的功能情况还需要进一步核实；同时归档了涉及20条记录的43张界面截图。本文按照分组依据和有无独立总览对这些记录进行归类，得到四种组织方式，具体见表2。 / 表2  平台AI评论摘要的四种组织方式 / 归类时先看页面有无独立总览，有且其后列有分项内容的，归为总分结合式；没有的再看分组依据，不分组的归为整体概括式，按商品属性分组的归为属性分项式，按优点和缺点分组的归为优缺点分组式。摘要的位置、默认展示范围、展开方式和原始评论入口另外记录。 / 5.2 实验分组与实验材料 / 实验采用2（分组依据：按属性、按优缺点）×2（独立总览：有、无）组间设计，形成四个实验组：A组为属性分项式，B组为优缺点分组式，C组为属性型总分结合式，D组为优缺点型总分结合式。另设E组为整体概括式，作为补充对照组。被试被随机分配到其中一组，每人只阅读一种摘要，以免被试比较不同页面后猜出研究目的。五组摘要来自同一份评论底稿，包含相同的商品属性、评价内容、效价和表达强度，只改变内容的组织方式。 / 底稿同时包含正面和负面评价。实际平台的AI评论摘要通常会同时概括优点和不足，同时提到正反两方面的信息也更可信（Eisend，2006；Jensen等，2013）；而且只有正面内容时，优缺点分组式无法成立。 / 各组摘要中正负评价的条数比例相同，并统一按先正后负的顺序排列。C组和D组的总览段落完全相同，后面的细项分别与A组和B组相同，因此C组与A组、D组与B组之间只差总览这一段。E组用一段连续文字写出底稿中的全部评价。制作材料时将记录各组字数，除总览外，各组篇幅尽量接近。各组的具体设计见表3。 / 表3  各实验组的摘要设计 / 实验情境选择日常运动鞋。问卷首先请被试设想自己准备购买一双日常穿着的运动鞋，正在浏览商品页面；然后展示带有AI评论摘要的模拟商品页面图片；最后请被试回答问卷题目。 / 五组页面使用相同的虚构品牌、商品图片、名称、价格、评分和评论数量，摘要的位置、卡片大小、字体、字号、颜色和“AI生成”标识也保持一致。摘要内容涵盖舒适性、透气性和耐磨性等属性，并全部展开显示。摘要中的比例信息统一用“多数用户”“少数用户”等文字表述；页面只展示AI评论摘要，没有原始评论和跳转入口。 / 这样测得的感知有用性只反映摘要本身；如果提供原始评论，被试是否翻看、看多少会因人而异。去掉原始评论会降低实验情境的真实感；另外，E组为连贯段落，其余四组为分条内容，E组与其他组的差别同时包含文字结构上的差别，比较结果只作为补充参考。这两点将在论文的研究局限中说明。 / 正式实验前，先进行少量认知访谈，了解被试对页面和题目的理解；再开展小规模预实验，检查图片是否清晰、各组摘要是否容易区分、各组内容是否被认为基本一致，并根据结果修改材料和问卷。 / 6. 变量测量 / 感知有用性和采纳意愿均采用李克特七级量表，1表示“非常不同意”，7表示“非常同意”。题项主要参考Cheung等（2008）的量表，并结合AI评论摘要情境进行改编，具体见表4。操纵检查和控制变量的测量见表5。 / 表4  变量测量题项 / 注：采纳意愿题项由原量表的过去行为表述改为当前情境下的意愿表述，AI3为根据本文定义补充的题项，所有题项将在预实验中检验和修改。 / 表5  操纵检查与控制变量的测量 / 注：操纵检查题项将根据预实验结果修改；AI摘要经验、商品熟悉度和网购频率作为控制变量。 / 7. 可行性分析 / 7.1 理论可行性 / 信息采纳模型发展比较成熟，在在线评论情境中已有大量应用，感知有用性和采纳意愿也有成熟的量表可以参考。本文的研究模型包含两个自变量、一个中介变量和一个因变量，2×2组间设计在消费者行为研究中应用较多，分析方法也比较成熟。 / 7.2 实施可行性 / 前期已经完成文献梳理和平台资料的初步整理，五组实验材料可以用同一个商品页面模板制作，在线问期卷平台也可以实现随机分组。样本量用G*Power估算：按中等效应量（f＝0.25）、0.05的显著性水平和0.8的统计功效，2×2双因素方差分析的主效应和交互效应共需约128份有效问卷；加入对照组后进行五组单因素比较，共需约200份，即每组约40份。考虑到会有一部分无效问卷，计划每组回收约50份，共约250份，最终样本量会根据预实验结果再作调整。
