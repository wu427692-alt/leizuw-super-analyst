## Jev 暂时下线

Jev 专属入口、旧文档入口及 API 停用，不影响仍在使用的“量化研究”。历史记录、检查点、代码和已有文件保留，不删除账户或资料，不安装、恢复或调用 Jev 服务。

应用启动不再加载 Jev 路由的持续模拟恢复生命周期。停用后的页面和接口仍保留原认证边界；已经授权的旧链接显示停用状态，而不是继续加载交易回测界面。恢复上线必须另行明确审核，不能仅因为历史状态仍为开启就自动恢复。
