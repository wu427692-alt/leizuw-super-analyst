# 公开介绍首页

## 范围与入口

公开介绍页位于 `/`，对应 `LandingPage.tsx` 与 `LandingPage.css`。它与登录后的市场总览 `/app` 是两个页面，本次设计不改变行情、业务接口、账户隔离或鉴权。

- 顶部注册与底部注册申请均指向 `/access?mode=register&redirect=%2Fapp`。
- 进入平台指向 `/app`；未登录用户仍由既有访问控制处理。
- `/guide` 使用手册公开可读，管理员入口仍为独立鉴权的 `/admin`。
- 顶部导航与页脚的“作者介绍”在新标签页打开 `https://leowu.leziwu.com`，不进入业务路由或发起数据请求；手机端保留页脚入口。
- 产品展示的五个标签对应市场、概念题材、自选股、深度调研和量化验证；补充入口为机构资料、数据下载、问股、任务与验证。

## 视觉与交互

采用冰白背景、浅橙与冷蓝环境光、磨砂玻璃导航和产品展示框。深色正文与橙色主按钮保持清晰对比；不跟随业务页面的深色主题切换。取消重复证据链、重复产品介绍和自动滚动跑马灯，保留一组可切换的产品导览。

玻璃材质使用标准与 Safari 前缀的 `backdrop-filter`，不支持时使用不透明浅色背景。滚动呈现仅作渐进增强，不依赖脚本隐藏内容；减少动态效果偏好会关闭动画、过渡与透视。移动端仍显示注册和进入平台，产品标签可水平滑动。

产品标签支持左右方向键、Home、End 和循环切换；当前标签与面板关联，只有当前标签进入 Tab 键序列。截图支持独立打开大图。页面开头提供跳至主要内容链接。

## 截图与数据口径

介绍页不发起行情、新闻、AI 或采集请求，只使用静态产品图片。全站现有登录状态检查不受影响。首屏图片优先加载，产品区域只挂载当前标签对应的图片并延迟加载，不预取所有功能页或所有截图。

所有图片是历史界面示意，不是实时行情。首屏明确标注“历史界面示意 · 非实时行情”，功能截图说明数据与界面以登录后为准。不以这些图片推断当前价格、数据规模、任务完成情况或最新版本状态。

## 验证

`src/pages/__tests__/LandingPage.test.tsx` 覆盖入口、全部产品切换、ARIA、键盘焦点、截图按需挂载和历史口径提示。浏览器验收覆盖桌面 1440 / 1280 与手机 390 / 320 宽度，检查横向溢出、截图解码、标签切换、右上角注册、脚本错误、减少动态效果及深色系统偏好。

本专题为中文产品页面说明，没有独立英文对应文档，因此不新增重复英文说明。

## 独立发布与回退

介绍页可以基于云端当前前端源码单独构建，仅替换本页组件、样式、HTML 站名与新增截图；不要直接发布含其他未验收业务修改的工作区构建。页面没有新增后端依赖，不需要重启网页或采集进程。

发布时先准备完整的新静态目录并保留旧版哈希资源，再切换 Nginx 静态目录和网页容器的 HTML 入口。同步保存本次首页源文件，避免下次完整构建恢复旧首页。旧入口、旧静态目录和被替换的源文件均需保留；验证失败时恢复旧入口和静态目录，不回滚数据库。上线后用公网验证桌面、手机、五个产品标签和图片，以及注册与未登录访问 `/app` 的拦截。
