# 小作文量化回测与数据利用

## 数据链路

页面使用知识星球 MCP 已同步到 `research_notes` 的原文、可选的 `essay_analysis_records` 结构化股票观点，以及 `stock_daily` / Tushare 日线。运行回测时只补取当前规则命中的高频股票，默认最多 30 只；不会无边界抓取全市场。

默认仅把 `essay_analysis_records` 中已经完成、通过重要度与置信度阈值的观点作为可交易事件，
避免大量未分析原文按股票关键词展开后夸大样本数。研究者可显式开启“原始语料探索层”：此时
未分析纪要会标记为 `raw_unanalyzed`，方向只由可复查关键词确定，重要度、置信度和信息增量保持
为 0。探索层不会冒充 AI 结论，页面会持续显示其数量与风险提示。

## 默认事件口径

- 事件日：小作文在上海时区的发布时间。
- 股票信号：DeepSeek 结构化结果中具有证券代码的股票观点。
- 买入价：事件日之后首个交易日开盘价。
- 卖出价：从买入日计数的第 5、10 或 20 个交易日收盘价。
- 未成熟样本：尚未走满相应持有期，不进入该周期胜率和平均收益。
- 超额收益：股票持有期收益减去同期沪深 300 收益。
- 复权：主动运行时同步 `adj_factor` 并按买卖两日因子计算；本地快速预览没有因子时会明确标注未复权。
- 首次提及：当前事件前的设定静默窗口内没有同一股票观点，默认窗口 180 日。
- 重复信号：同一股票、研究组和方向默认在 3 个自然日内聚类为一个事件，可设置为 0～30 日。
- 交易成本：默认从每个事件收益中扣除 12bp，可设置为 0～200bp；结果页同时展示成本敏感性。

## 六个研究工作区

- **研究总览**：五步研究管线、可用方法、真实本地数据资产和最近结果。
- **策略工坊**：按信号、样本、交易约束和验证方式配置规则。
- **自然语言回测**：DeepSeek 将需求转换为受约束的研究任务；服务端生成模板代码，用户确认后执行。
- **结果实验室**：组合收益/回撤、事件路径、收益分布、95% 自助法置信区间、t 值、盈亏比、成本敏感性、月度队列和多持有期对照。
- **数据资产**：从 SQLite 现场读取各域记录数、最近时间、状态和本次样本漏斗。
- **运行历史**：保留规则、数据哈希、行情截止和完整结果快照。

自然语言接口不执行模型自由生成的 Python。模型只能填写白名单字段；代码由服务器拥有的固定模板
生成，执行器不开放 `exec`/`eval`、Shell、任意 SQL、文件系统、密钥、下单或未授权网络访问。

## 研究组与吹票强度

研究组优先从标题中的 `【券商+行业组/团队】` 识别，其次匹配已知券商与卖方行业团队组合。普通知识星球作者和公司名归入“其他来源”，继续参与全量事件研究，但不进入券商研究组榜。规则关键词会同时匹配星球名、作者、标题和正文。

“吹票强度”由结构化重要度、信息增量和强观点用词组成，只用于研究观点强弱和后续走势的关系，不代表相关内容已被证实。

研究组排行榜展示原始胜率，同时使用 10 个胜率 50% 的中性先验收缩排名分；至少 3 个到期样本才进入主排名，小样本保留展示但排在成熟团队之后。

知识星球 MCP 每次增量入库或历史回填完成后，会触发受节流的后台预计算 worker。默认基线扫描已完成的结构化分析；旧纪要仍保留在本地供检索和显式探索，不为回测强制消耗 AI。事件全集不会再因“最多补行情股票数”被截断：后台每轮只限制 Tushare 行情补取数量，已经具备本地行情的其他股票和研究组仍全部参与排名。

若已解析股票尚无本地日线，worker 每轮按提及量补 60 只，30 分钟后继续下一批，直到行情覆盖完成。后台统一使用本地原始日线计算，避免分批补取时把“本轮有复权因子”和“存量无复权因子”的收益混排；用户主动运行单条规则时仍使用当次 Tushare 复权因子，并在数据质量区明确价格口径。

历史原文证券识别和事件收益计算运行在独立后台进程，不占用 Web API 的 Python 执行锁；结果通过 WAL 模式写入同一 SQLite 快照表，前端在计算期间继续读取上一次完整结果。

前端默认读取独立的“全机构基线”接口。用户运行单机构规则时会即时看到该结果，但它不会覆盖下一次打开页面时的全机构排行榜。应用重启会复用六小时内最近基线；只有知识星球产生内容增量或基线过期才重新计算。

所有六位证券代码在进入事件库前必须命中本地 A 股主数据索引。原文日期、订单号和金额等形似六位代码的数字会被过滤；若同段原文包含明确公司名称，名称匹配得到的真实证券代码仍正常保留。

## 趋势与组合

趋势信号综合首次提及、重要度、MA5/MA20 与 20 日动量。主动运行时，事件收益、均线动量和组合净值统一使用 Tushare 复权因子。组合优先选择主榜中排名靠前的成熟研究组，再按趋势强度和动量选择不重复股票；数量不足时才由小样本团队和其他来源补位，最终按等权生成最近 60 个共同交易日净值。当前引擎扣除规则中设置的固定交易成本，但尚未逐笔模拟涨跌停无法成交、冲击成本和容量，不会自动下单，也不构成投资建议。

## API

- `GET /api/v1/essay-quant/dashboard`：最近一次持久化结果；没有历史运行时使用本地日线快速计算。
- `GET /api/v1/essay-quant/institution-dashboard`：最近一次后台全机构基线；不会被用户运行的单机构自定义规则覆盖。
- `GET /api/v1/essay-quant/rules`：规则列表。
- `POST /api/v1/essay-quant/rules`：保存规则。
- `PUT /api/v1/essay-quant/rules/{id}`：更新规则。
- `POST /api/v1/essay-quant/run`：补取限定行情、运行并保存回测快照。
- `GET /api/v1/essay-quant/precompute/status`：后台机构排名预计算状态与最近结果。
- `POST /api/v1/essay-quant/precompute/run`：立即标记全量机构排名重算；worker 自动去重和节流。
- `GET /api/v1/essay-quant/research-catalog`：真实数据资产、研究方法与防过拟合护栏。
- `GET /api/v1/essay-quant/runs`：读取最近 1～100 个不可变运行快照摘要。
- `POST /api/v1/essay-quant/natural-language/plan`：让 DeepSeek 生成结构化任务、假设和受控模板代码。
- `POST /api/v1/essay-quant/natural-language/execute`：确认后执行已通过 Pydantic 与服务端归一化校验的规则。

每次运行保留完整规则 JSON、结果 JSON、事件源哈希、行情截止日、事件数与成熟样本数，便于复查。
