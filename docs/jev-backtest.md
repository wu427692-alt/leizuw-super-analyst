# Jev 分钟交易回测

> 当前状态：按用户要求暂时下线。导航、旧页面与 API 不再提供该功能，不自动恢复持续模拟；历史资料与代码保留。以下为历史实现说明，不是当前可用入口，也不授权安装、调用或重新启用 Jev。仍在使用的“量化研究”不受影响。

页面 `/jev-backtest` 默认使用新浪公开近期分钟快照，可切换 Tushare `stk_mins` 历史分钟行情，支持 1、5、15 分钟。Jev 接收截至当前收盘的归一化 OHLCV 窗口与量价指标，直接输出 BUY、SELL 或 HOLD。每根输入都包含成交量，以及相对近 20 根均量的比例；页面成交量柱与价格和回放游标一致。公司、日期、新闻、基本面和账户信息不进入模型。

## 回放与重复实验

选择股票、日期和周期后提交一次付费任务。运行中展示每根行情推进后的账户状态；完成后可播放、暂停、调整速度和拖动进度，查看当时现金、持仓、已实现与未实现利润。播放本身不调用模型。

改变置信度门槛、仓位比例、手续费、滑点、止盈止损、持有根数和结算假设后可重新回测。相同所有者、模型、固定问题版本与量价输入的判断会复用；改变窗口或数据导致输入变化时才重新付费。取消刷新行情会使用相同区间的历史行情快照（首次仍需加载）。请求编号幂等；同账户一次只允许一个活动任务。不同账户的结果和缓存隔离。

## 成交语义

- 当前根收盘形成信号，在下一根已提供行情的开盘尝试成交，不使用同根最低价或最高价挑选成交。
- 只做多、现金账户、100 股一手，按设定比例分配现金。初始空仓，不加杠杆或做空。
- 默认 `t1`：买入日按上海日期判断，次日才能卖出；`research_t0` 仅用于假设实验，不能视作 A 股可执行规则。
- 0 成交量、已知停牌、对应方向涨跌停或滑点超出价格限制时不成交。缺少完整交易所元数据时明确显示数据限制。
- 可设置持有根数、收盘触发的止损/止盈；这些均为独立规则退出，仍受下一根成交及 T+1 约束，不冒充 Jev 决策。
- 买入持有与 MA5/20 基线采用相同费用与成交约束，不使用 Jev 的额外规则退出。期末仍持仓时按收盘估值，不虚构平仓。
- 复权因子变化时拒绝回测，避免把除权价格缺口当成收益；未提供因子时明确标记未核验。分钟 K 线不能复原盘口队列、逐笔流动性或历史费用政策。

置信度是模型分类置信度，不是盈利概率。历史回放仍可能受模型预训练和重复调参偏差影响；应将调参区间和之后的测试区间分开。没有真实交易接口，也不会发送券商订单。

## 配置与费用

`JEV_MODEL`、`JEV_DECISIONS_ENDPOINT`、`JEV_TIMEOUT_SECONDS` 和 `JEV_LOCAL_BUDGET_RATE_PER_MILLION` 控制专用 WorldSeek SystemOne 客户端，均在 `.env.example` 列出。默认调用 `https://jev.worldseek-ai.com/v1/systemone`，请求仅包含 `state/questions`，当前响应模型核验为 `Qwen/Qwen3.5-9B`。macOS 默认从 `JEV_KEYCHAIN_SERVICE=codex.jev-use.worldseek` 指定的专用钥匙串读取；服务器可通过专用私密运行时变量 `JEV_API_KEY` 注入。不会自动借用通用 LLM 渠道，也不切换模型或充值。

默认单次本地预算 $0.20、允许上限 $0.50。WorldSeek 当前响应不提供费用，供应商价格与账户侧额度尚未核验；原 OpenRouter 月限额不适用于本入口。`JEV_LOCAL_BUDGET_RATE_PER_MILLION` 默认 1，只是每百万输入 token 的本地预算系数，不代表供应商价格，不能保证账单美元上限。发送前按最大 32K 输入预留预算，若供应商明确返回费用则使用其值；未给费用时保留 `actual_cost=null`，旧兼容 `cost` 字段仅保存本地预算估值并标记 `cost_basis=unverified_local_budget` 并在页面显示未核验预算估值。保留请求数量、单次调用和任务预算限制。传输中断的不确定费用保留预留额。达到预算即停止，不将未执行区间显示为完整回测。付费任务中断不自动重试；新建任务可复用已缓存判断。

新浪每次最多取得 1970 根近期原始行情，超出日期覆盖或缺少预热会明确报错。保留缺失分钟，不插值；成交量保持来源原始单位，模型使用相对量，不按未经核验的股/手口径换算。公司行动、交易所涨跌停和停牌资料缺失时标注未核验；不能据此判断实际可成交容量。

2026-09-20 对网站及个人已配置 Token 的两个入口实测，`stk_mins` 均返回每小时 1 次限制；这只描述该接口的当前返回，不代表其他高级权限或购买记录。Tushare 分钟权限与积分分开，保留为可选来源。一次请求合并预热与评估区间，排序去重并校验原始 OHLCV，不使用日线插值；实际节假日按其交易日历过滤，原始返回达到 8000 行时拒绝使用可能被截断的数据。修改条件重跑可保留行情快照。默认最近两个已结束工作日，最多 2000 根评估行情。

## Mac mini 容器凭据

可配置非秘密 `JEV_RELAY_URL=http://127.0.0.1:<端口>`。宿主 `scripts/jev_keychain_relay_host.py` 从专用钥匙串读取凭据，通过保持打开的匿名 stdin 管道送给当前容器中的 `src.services.jev_runtime_relay`。relay 只在容器 loopback 监听，仅接收严格量价输入，凭据只存在内存；宿主管道关闭时 relay 退出。没有把钥匙串或 Docker socket 挂到应用容器，也不将密钥放入 Docker 环境或配置文件。

宿主启动参数包含专用服务名、账户、Docker 路径/context/容器和端口；采用 LaunchAgent 保活时，容器重启后重新读取钥匙串并启动 relay。`scripts/jev_keychain_store.py` 可从 stdin 初次写入专用钥匙串，以 Security.framework 创建仅预授权 `/usr/bin/security` 读取的条目，已有条目不会覆盖；凭据不出现在命令参数。

独立发布可用 `npm run build:jev`，将 `apps/dsa-web/dist-jev/` 放入默认 `static/jev-backtest/`，或用非秘密 `JEV_FRONTEND_DIR` 指定目录。后端在 `/jev-backtest` 提供受登录保护的入口。`/access?redirect=/jev-backtest...` 使用独立包复用网站登录组件，认证成功后整页跳回原回测地址并保留参数，避免旧 SPA 的内部导航落到 404。仅 `/jev-backtest-assets/assets/` 下的代码与样式公开以加载登录界面，回测 API 和结果仍要求已批准用户或管理员会话。这样可保留现有 SPA 静态产物；主 SPA 也包含同一路由，后续全站发布可继续复用同一组件。

## 接口与验证

`GET /api/v1/jev-backtest/capabilities`、任务列表与详情均不调用模型。`POST /tasks` 显式提交付费回测；`POST /tasks/{id}/cancel` 停止后续请求。所有接口要求已批准用户或管理员会话，并禁止私有响应缓存。

离线测试覆盖时间顺序、分钟 T+1、下一根成交、费用、模型响应校验、预算停止、缓存隔离和重复请求。前端测试检查逐步回放不暴露未来信号，以及私有账户切换时清除任务状态。真实服务验证应使用有界公共行情并记录实际调用数量与费用，不保存凭据。

参考实现为 [trade-jev](https://github.com/justinhe16/trade-jev) 的信号缓存和执行重放思路；本站使用现有界面和自行实现的 A 股模拟规则。接口规格见 [Tushare 历史分钟](https://tushare.pro/document/2?doc_id=370) 和 [WorldSeek Jev SystemOne](https://jev.worldseek-ai.com/v1/systemone)。
