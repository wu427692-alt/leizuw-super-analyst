# 网站使用手册

`/guide` 是无需登录的操作手册，产品介绍首页和应用内导航均有入口。手册只读取随前端发布的说明与历史截图，不查询用户任务，不触发数据同步、转写或 AI 调用。进入具体业务页面后仍执行原有登录和权限检查。

## 检索与定位

- 搜索范围包括工作台名称、用途、数据、步骤、子模块、操作、输出和核验项。
- 多个词用空格分隔，按“全部包含”组合检索；英文不区分大小写，兼容全角字母。它不是平台数据搜索，也不调用模型。
- 命中结果在输入框下显示所属工作台和相关子模块说明，点击“阅读步骤”定位对应章节。
- 分类筛选与关键词共同生效；无结果时就地清除筛选。
- 完整目录一直保留全部入口。选择被筛掉的章节时先清除筛选、再定位并移动键盘焦点，避免跳到不存在的目标。
- 快捷任务入口和章节 `#id` 可直接定位。手机可从搜索结果或快捷任务卡进入详细章节。

## 截图与阅读

- 截图明确标为历史实机参考，不代表当前行情、任务或实时接口状态。
- 自选股示例使用有数据的真实历史截图，按当前图像位置重标操作点；不再展示旧空白自选页和机构语料加载页。机构语料的文字步骤及子功能入口继续完整保留。
- 原图保持比例，避免裁切导致标注错位。局部操作说明默认折叠，展开时才挂载对应放大背景图，减少重复内容和初始图片渲染。
- 预览使用浏览器原生模态窗口，背景不接收焦点；支持关闭按钮、Escape、点击背景和原尺寸图片链接。关闭后恢复触发按钮焦点及原来的页面滚动设置。
- 手册沿用介绍首页的冰白／浅蓝磨砂玻璃与深橙色强调，导航、检索、目录、章节和截图预览使用统一材质；正文保持深色字与高对比阅读底，不随应用深色主题切成低对比背景。
- 毛玻璃只用于少量外层区域；章节正文、表格及局部截图不逐行叠加模糊。低透明度偏好或不支持模糊的浏览器使用实色底，不影响检索、目录定位和原图查看。

## 与当前功能对齐

- 公司调研：明确行业/上市公司两种模式，支持个人报告标题搜索、状态筛选与分页；区分完整完成、有限完成与失败，并说明 Word/PDF 下载。
- 录音：直达 `/essay-radar/feed?tab=audio`；区分仅转写与 AI 纪要。单份原文字稿 TXT、批量原文字稿 ZIP 与纪要 Word/Markdown/JSON/完整包分开说明，不把个人纪要称为新增公共小作文。
- 量化：六个子页使用真实 `section` 路由；历史结果应从具体任务进入，不宣称存在尚未实现的状态筛选或失败重跑按钮。
- 一站式取数：研报筛选 `?view=reports` 与跨渠道任务 `?view=tasks` 分开。研报人工勾选导出所选 Excel（含 PDF 链接，不等同 PDF 文件）；跨渠道按审阅确认的来源条件执行。后台阶段百分比与最终 ZIP 的下载字节进度不是同一指标。
- 问股：普通用户说明不再包含管理员全局通知能力。

## 验证与边界

- 前端回归：手册检索、多词匹配、分类清除、隐藏章节导航、原生预览生命周期、真实资源路径和子页链接；同时回归公开介绍首页。
- 浏览器验证：桌面 1440/1280 与手机 390/320 宽度的检索、章节定位、子模块展开、截图预览、键盘关闭与焦点恢复，无页面横向溢出。
- 这轮验证的是手册交互与当前代码中的入口契约，不等于重新执行付费转写、量化回测或完整公司调研任务。
- 尚未补拍所有新业务界面。历史截图只作定位参考，不能宣称为当前生产版本截图。
- 此文档专门描述 Web 手册；`full-guide.md` / `full-guide_EN.md` 是配置部署文档，不属于本次更新内容。
