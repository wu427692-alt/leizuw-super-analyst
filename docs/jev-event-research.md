# Jev 秒级交易研究

> 当前状态：暂时下线。页面和 API 停用，保留历史研究产物；下列参数、示例和部署方法仅供历史代码审查，不作为当前可用功能或自动恢复指引。

入口为 `/jev-backtest?lab=convertible-t`，沿用网站登录。它与原分钟回测共享任务存储机制，但使用独立身份命名空间与严格模型输入协议。没有券商下单接口。

## 数据与因子

秒级不等于每秒有一笔成交。本系统使用记录的逐笔事件，或按接收时间聚合的真实一秒区间；无事件秒保持缺失。`scripts/prepare_jev_tick_sample.py` 可把已下载的 Databento MBP-1 CSV gzip 转换为有来源哈希的研究数据。只累计 `T` 成交的真实股数及价格乘数量，不把挂撤单当成交，不用秒末价格乘全天累计量制造 VWAP。整秒结束时才能知道该秒全部内容，后续订单不能利用其产生之前的区间成交量。

2026-09-20 校验的公开样本为 NVDA 2025-09-16：2,400,522 条原始事件，正常交易时段 279,210 条成交记录，22,205,350 股，23,348 个有更新的秒桶。23,400 个自然秒中 52 秒无更新，最大相邻间隔 3 秒；没有插值。来源是纳斯达克单一场所最优档，并非全市场 NBBO。

模型因子包括归一化价量、实际时间跨度的短期收益、波动、相对成交量、真实成交额 VWAP 偏离；启用盘口时加入价差、买卖委托量不平衡、微价格偏离。关闭某组会从模型输入移除该组数值，撮合仍使用真实盘口。正股、板块、大盘和转股溢价接口保留，缺少同时点数据则禁用。外部因子要求 `asof` 和 `available_at`，按历史时点向前查询，过期或缺失不会填零。当前板块成员不被当成历史成员。

现有华懋转债数据只有 2026-08-20 约十分钟的 441 条采集快照，与正股、大盘留存秒数据不重叠；成交量口径、旧交易所路由及完整日也未核验。页面保留该标的并显示未就绪，不生成其秒级回测收益。

## 资金与执行

- 初始为 20 万底仓市值与 20 万现金；底仓向下取整到交易单位，剩余估值金额归现金，合计保持 40 万。
- 转债使用 CNY、10 张交易单位、0.001 元价格单位。美股使用 USD、1 股单位、0.01 美元价格单位，明确采用不借款、不做空的保证金式仿真账本。币种不隐含换汇；这不是美股现金账户结算模拟，也不替代经纪商适当性与保证金检查。
- 仅在信号之后的真实事件尝试成交，等待时间取配置延迟与原模型实测延迟较大值。缓存重放仍保留原响应延迟。按买一/卖一和不利方向滑点、价格单位处理；增量成交量参与率、可见挂单量、现金和库存共同约束成交。
- 开启实测延迟时，下一次模型判断还需等待上一响应返回，包括 HOLD 和低置信度响应；一秒节拍不意味着每秒都能完成一次判断。执行版本为 `event-execution-v2-serial-model`，旧信号缓存可复用。
- 最低佣金按一张模拟委托累计，部分成交不重复收整笔最低费；佣金、滑点及其他费用均可配置。默认费率是研究假设，未复原特定历史券商和全部监管费用。
- 过期盘口、无可靠增量成交量、信号等待期与成交量区间重叠时不能据此成交。历史排队、隐藏流动性、真实冲击和全部交易所停牌/价格带并未重建。
- 收盘或配置的研究窗口结束前尝试恢复初始底仓；恢复也经过同样撮合。无法恢复的库存差保留，不凭空补一笔平仓。

“增量做 T 收益”是策略权益减去同一时刻底仓不动的权益，不把转债/股票本身涨幅算作做 T 盈利。它包含期末库存差的市值影响，不自动等于已实现收益。总收益、库存差、现金、成本与基准分别记录。

## 多轮研究与复现

`scripts/run_jev_event_research.py` 是显式付费命令，GET 页面、刷新和回放均不会触发它。运行前保存数据哈希、固定问题哈希、因子版本、时间划分、参数网格、选取标准和费用上限。全部轮次，包括亏损和失败，都会保留。相同输入复用信号，只改变费用、门槛、数量或延迟不会重新付模型费。

首轮研究提前锁定同日训练、验证、最终测试三段；只用训练段选条件，后两段不再选参，再对锁定条件提高成本与延迟、降低成交参与率。单日、单标的结果只能检验机制和提出后续假设，不能证明稳定超额收益；模型预训练、市场状态单一及多重试验偏差仍须独立评估。模型分类置信度不是盈利概率。

已完成的 15 轮采用一秒行情、每 30 秒判断。每段前约 60 秒积累 61 条事件，期间只持底仓，未使用窗口前预热。训练胜者增量 +8.47 USD，锁定后的验证 -386.37 USD、最终测试 -297.07 USD、压力测试 -570.48 USD，未验证稳定正收益。该方案由模型方向与窗口末恢复规则共同组成：训练胜者的买回来自恢复规则，不能表述为模型独立完成双向做 T。362 次付费请求合计 $0.116877138，另有 698 次缓存复用；模型 API 费用另列，未计入交易成本后的策略盈亏。

完整任务保存资金曲线、信号、委托、部分成交、恢复失败与来源记录。回放按事件索引裁剪，精确区分同一时间戳下的先后事件，不暴露未来行情和信号。实时预览保留最近 2,000 点，完整结果保存全轨迹。

页面可成对指定带时区的日内研究起止时间；同时留空才按整个日期区间运行。载入历史实验时保留原窗口、时区及费用上限精度，再改条件不会默默扩大研究时间。费用输入允许保存任务的完整小数，仍受服务端单任务上限约束。

另用未参与核心研究的 12:00–12:08 做了两轮固定节拍审计，沿用训练锁定条件，不重新选参。一秒配置受串行响应限制，实际判断间隔中位数为两秒，净增量 -133.22 USD；30 秒配置为 -8.69 USD。追加 60 次实调花费 $0.02096199，另一轮复用 4 次信号；两类实验合计 $0.137839128。该短窗口对照说明更密集调用不自动提高收益，不能充当新策略的独立盈利验证。

## 配置与数据目录

`JEV_CB_DATA_DIR` 指向服务器管理的数据目录。`catalog.json` 列出可用数据集 ID 与相对文件，数据集包含标的制度、单位、真实事件、覆盖声明和时点因子。路径须留在该目录内，用户不能提交任意文件路径。`research.json` 为本地研究脚本生成的结果摘要。元数据、单位、排序、时区、区间完整性检查未通过时，在读取凭据和调用模型之前失败。

公开样本结果显式保存到 `research-results/<UUID>.json`，顶层需 `visibility: public_sample` 和已完成状态，并列入研究摘要。登录用户通过 `/api/v1/jev-convertible-t/research/rounds/<UUID>` 查看投影后的公共样本；页面参数为 `round=<UUID>`。普通任务仍由 `task=<UUID>` 和账号身份隔离，不能凭样本清单访问其他账号任务。公开 reader 拒绝符号链接、非普通文件、越界和超过 32 MiB 的文件，不返回账号、请求编号和内部路径。

Jev 凭据和 relay 配置沿用 [分钟回测说明](jev-backtest.md)。每任务默认费用上限 $0.20、最高 $0.50；研究脚本另有整轮总预算。网络或上游错误不自动重试，不自动充值。旧缓存、不同模型、固定问题版本或因子输入不会混用。
