# 问股工作区

入口：登录后打开 `/chat`。选择通用分析或具体策略，输入问题后点击“发送”；中文输入法确认候选词不会直接发送，`Shift+Enter` 换行。

## 会话与恢复

- 左侧对话列表和当前会话独立读取；读取失败显示就地重试，不把失败当作没有历史。
- 历史未准备好时暂不允许续问，避免脱离原会话上下文。切换、新建或更换账号后，旧请求不能覆盖当前内容。
- `/chat?session=<会话编号>` 可恢复指定会话，包括不在最近 50 个列表内的旧会话。编号不是访问凭证，服务器仍按当前用户校验。
- 历史默认读取最近 100 条，按时间正序展示；不是全历史导出。会话导出包含当前已加载消息。机器人历史详情同样使用最近 N 条；模型上下文读取不受此展示调整影响。
- 正常切到其他功能时，当前浏览器中的回答连接可以继续；切换会话、关闭网页或“停止等待”会断开当前连接。**停止等待不等于取消后台模型，也不保证免除已经发生的调用费用。**
- 连接断开、正文为空或返回格式异常不会生成“无内容”并冒充完成。已显示的问题、历史和处理进度保留。
- “重新读取会话”仅获取服务端已保存内容，不重新调用 AI；若本次问题尚未入库，保留本地问题。只有问题、尚无答案时保留恢复入口。可稍后再次读取。
- “重新编辑上次问题”只放回输入框，不发送。再次点击“发送”会产生新的分析调用；请先确认旧任务是否已经保存结果。

## 用户与管理员边界

浏览器仅保存按身份区分的会话编号，不持久化正文。登录身份变化时，清理旧会话、草稿、临时错误和完成提醒；浏览器禁用存储不影响当前页面使用。旧版无身份的会话编号不会自动迁移，可从历史列表重新选择。

普通用户不读取或修改全局模型上下文压缩配置，不向管理员配置的全局机器人/邮箱发送会话。管理员和关闭用户访问控制的本地模式保留这些操作。复制、当前会话导出和策略选择不受影响。

## API 和后台执行约定

- POST `/api/v1/agent/chat`、`/api/v1/agent/chat/stream` 的执行线程显式继承请求身份，模型工具和本地数据查询使用同一用户边界。
- 本地共享个股底稿或补全缓存读取异常时，继续尝试既有的按需 Tushare 补全，不丢弃已取得或调用方提供的证据。保持原 12 个资源、日期范围和并发上限；内部取数线程也继承请求身份。全部为空、部分失败和全部失败分别标记，不把缺失数据描述为已取得。
- SSE 业务事件携带原始 `session_id`；每 15 秒发送注释型保活，不显示为进度。
- 连续 300 秒没有业务事件时，连接返回 `error` 和 `background_continues: true`。此状态表示连接等待到期，不代表模型已停止或必然完成。
- 客户端断开后不再向其投递事件；执行器仍可保存最终结果。真实模型异常返回错误，不伪装成功。
- 只有有效 `done` 且非空正文才视为收到完整回答；只读恢复和自动读取列表不会重试 AI POST。

## 验证边界

回归测试覆盖真实线程身份、SQLite 会话隔离、长会话尾部、ASGI 断线、SSE 分帧、迟到响应、停止等待、只读恢复、身份变化和手机输入。浏览器交互测试使用明确标注的受控数据，不代表实时投资分析质量或真实上游可用性保证。
