# 行业调研：极速研究工作台

## 目标

“行业调研”把研报、机构段子与录音、公告、行情财务、企业事实、新闻和公开评论组织为一个可持续的研究课题。系统不设置人为等待时间：先尽快生成可用的证据蓝图，再由后台继续完成产业链、公司候选、趋势与瓶颈验证、反证和持续监控清单。

## 方法来源

- CIA Intelligence Cycle 用于定义“规划—收集—处理—分析—分发”的循环任务结构。
- PRISMA 2020 与 PRISMA-ScR 用于约束资料来源、纳入标准、检索、筛选、证据整理和排除原因。
- MSCI GICS 的层级分类思路用于提醒研究者先固定行业边界，避免把相邻产品、行业与应用场景混为一谈。
- 对标准驱动行业（例如光模块）应把 IEEE 802.3 等标准组织列为高等级验证来源。

## 极速流程

1. **立即：定义边界**
   - 确认研究类型、目标、包含项、排除项、核心术语和同义词。
   - 产出行业口径、检索式和七个必答问题。
2. **数秒至数分钟：建立产业链**
   - 沿原料、设备、部件、系统、客户和应用场景追踪价值量、成本与议价权。
   - 产出产业链地图、关键参与者候选和数据缺口。
3. **后台并行：验证龙头与趋势**
   - 用研报、公告、财务、行情、公司事实和非结构化语料交叉验证。
   - 产出公司对比、短中长期趋势、分歧和反面证据。
4. **证据就绪即输出：形成结论**
   - AI 只能引用固定证据快照中的 `evidence_id`，无证据结论必须标记为“待验证”。
   - 产出研究报告、访谈问题、证伪条件和持续监控指标。

## 数据与证据等级

| 数据组 | 主要用途 | 默认证据等级 |
| --- | --- | --- |
| 券商研报与 PDF | 行业框架、盈利预测、公司覆盖 | 经报道/可追溯 |
| 机构段子、录音与文件 | 产业线索、专家观点、最新变化 | 待核验 |
| 公告与治理事实 | 公司披露、重大事项、治理变化 | 事实 |
| 行情、财务与资金 | 趋势验证、业绩与资金反馈 | 事实 |
| 企业与工商事实 | 股权、司法、知识产权、经营事实 | 事实 |
| 新闻与公开评论 | 事件线索、市场分歧与情绪 | 混合 |

知识星球调研纪要同时进入原始语料库和统一情报事件库。行业调研在计数时排除事件镜像，避免同一篇材料重复计数。

## API

- `GET /api/v1/industry-research/methodology`：读取研究方法。
- `GET /api/v1/industry-research/blueprint?topic=光模块&lookback_days=730`：从本地库生成证据蓝图，不创建课题。
- `POST /api/v1/industry-research/projects`：创建当前用户的后台课题。
- `GET /api/v1/industry-research/projects`：列出当前用户课题。
- `GET /api/v1/industry-research/projects/{project_id}`：读取进度、证据快照和报告。

课题按用户隔离，状态和证据快照持久化。用户无需停留在页面等待；服务重启时，未完成课题会重新进入后台队列。AI 未配置时仍会立即保留证据底稿，并明确说明结论待人工或 AI 复核。

证据蓝图按课题短时缓存，并在服务启动后预热“光模块”示例，避免多人同时重复扫描大语料库。缓存最多保留 5 分钟，页面仍展示真实采集时间。

## 当前边界

- 通用行业默认只使用用户输入词；光模块、低空经济和人工智能有首批同义词扩展。后续应把同义词与产业分类维护成可审计词库。
- 研报库尚未覆盖的行业会显示为数据缺口，不会用机构段子替代正式研报事实。
- 公司出现频次仅用于确定研究优先级，不等于龙头排名、推荐或收益预测。
- 任务运行在当前服务实例的持久化队列中；未来多实例部署时应迁移到共享任务队列。
