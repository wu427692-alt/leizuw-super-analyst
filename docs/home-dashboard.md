# 首页市场大看板

Web 首页现在是面向盘前、盘中和盘后快速判断的市场总览大看板，聚合整体行情、海内外指数、自选股与本地投资情报。

## 数据内容

- A 股：上证指数、深证成指、创业板指、沪深 300，展示最新收盘、涨跌幅、近 12 个交易日趋势和成交额。
- 市场温度：全市场上涨、下跌、平盘、涨停和跌停家数，以及涨跌幅区间分布。
- 跨境资金：沪深港通北向资金净流入。
- 海外市场：恒生、标普 500、纳斯达克、道琼斯、日经 225 和富时 100。
- 自选股：行情、趋势、机会/风险分、投资者/上市公司/机构三视角情报，以及最新催化、风险和机构观点。
- 情报流：统一投资情报库中最新的公告、研报、新闻和知识星球小作文。

## 接口

`GET /api/v1/home-dashboard`

查询参数：

- `force=false`：默认使用最多五分钟的服务端缓存。
- `force=true`：用户点击“刷新数据”时绕过缓存，重新聚合行情和情报。

响应由 `cn_indices`、`global_indices`、`breadth`、`northbound`、`watchlist`、`latest_events` 和 `warnings` 等字段组成。某个外部数据源失败时接口会保留其他板块，并通过 `warnings` 返回降级提示。

## 刷新策略

首页不会每分钟逐只重复获取自选股。首次进入或缓存过期后聚合一次，五分钟内的普通访问直接复用缓存；手动刷新才会强制更新。自选股情报来自本地统一事件库，并按股票独立查询近 30 天内容。

## 数据单位

Tushare `index_daily.amount` 的单位为千元，服务端已统一换算为亿元后再展示；个股实时行情成交额继续按数据源返回的人民币元自动缩写。
