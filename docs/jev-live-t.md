# Jev 实时做 T 模拟

> 当前状态：暂时下线。网站启动不再自动加载本模块或恢复持续模拟，保留历史账户、费用、检查点和运行记录。以下为历史技术说明，不是当前操作指引；重新开启需要单独明确授权。

页面 `/jev-backtest?lab=live-t` 提供持续纸上账户的显式开启/关闭，以及既有运行记录。它使用当时接收到的实时公开报价，在模型返回后模拟执行，并与一直不动的初始底仓比较。没有券商连接或真实委托接口，打开、刷新页面和读取 API 不会调用付费模型或开启账户。管理员点击“开启”才启动持续运行；“关闭”会撤销未成交模拟单并结算已发模型请求，不强制清仓。

## 行情与模型输入

默认每秒轮询新浪公开盘口快照。供应商实际更新通常约三秒，页面分别显示源时间、接收时间和观测到的更新间隔；这不是交易所逐笔、每秒成交数据或 Level 2。成交量和盘口数量按已核验的股口径读取，累计成交额为人民币元。首条数据与断档后的第一条数据只建立累计基线，不把未知区间填为零成交。没有插值或补造缺失报价。

初始预热至少 60 秒，积累 20 条有真实量差的有效新事件。默认 `market-news` 模式向 Jev 提供归一化量价窗口、成交量、盘口价差及数量因子，以及沪深300（sh000300）、中证1000（sh000852）的当日和已观测30/60秒收益、个股相对指数表现。为判断新闻相关性，另提供公开股票代码、名称及决策时刻；资金、持仓和账户身份不发送。`--context price-volume` 可显式使用原量价与上证指数基线。重复报价不触发新推理，一次最多一个模型请求和一个待成交模拟委托。

CPO 使用东方财富 BK1128 的当次实际成分集合，加新浪实时个股快照计算等权收益、上涨比例、平均价差和覆盖率，明确标为“CPO成分股等权参考（非官方板块指数）”。成分信息在每日实际首次取得时冻结，跨上海自然日重新获取，不回填历史可知时刻；不支持或缺失的成员仍计入覆盖率分母。有效覆盖须至少80%，聚合时个股报价不超过15秒。上下文采集独立于个股撮合，每15秒刷新；模型提交时再次计算年龄，指数或CPO超过15秒则禁用并等待更新。

新闻每60秒只读已有公共快讯缓存，来源限于配置中的财联社、新浪、同花顺、东方财富、华尔街见闻和第一财经公开新闻。检查采集成功与入库高水位是否在300秒内，从近6小时选至多8条与目标、CPO或大盘相关的标题，保留原发布时间、实际取得时间和媒体名称。读取快照超过180秒失效，不发送私有知识星球材料。新闻作为不可信数据供模型判断，不执行其中指令。四组上下文均有效才允许本模式付费推理；到期仍未就绪则显示“未调用模型”，不退化成缺数据的付费实验。

页面区分“当前已收集的数据”和“最近真正提交模型的数据”，显示来源、时点、覆盖和缺失原因。全部时间统一为上海时区。未固定历史轮次的最新页面继续轻量轮询，以发现新启动的记录。

网络请求有独立进程硬超时；行情连续失败三次或模型失败时停止。模型侧在一次持续运行中复用有界私有worker和HTTP连接，减少逐次启动与TLS连接开销；每次调用仍有独立真实时钟截止，超时终止worker，HTTP失败和未知结果不自动重发收费请求。停止账户会关闭该worker。休市、过期、乱序和断档数据不能撮合。每轮取数后及发起推理前重新检查连续竞价时段与试跑截止时刻，停止后到达的模型结果仅用于结算费用。页面超过 15 秒未见进程心跳时显示暂停与过期数据，心跳恢复后继续读取；该提示不修改保存的记录，也不自动重启进程。

## 账户与成交约束

华懋科技试跑按首个有效价格将 800 万元现值折算为 100 股整手昨仓，余款加入 400 万元现金，总初始权益仍为 1200 万元。其他金额可通过命令行明确指定。历史买入成本未知，因此不显示实际成本价。

遵循 A 股 T+1：仅昨日可卖库存能够卖出，今日买入冻结；买回的股份不能重复充当当日可卖底仓。默认每个信号最多 1000 股，库存偏离限制为初始底仓的 20%。本轮启用 `--confidence-sizing`：BUY/SELL/HOLD 独立决定方向，不用置信度拦截买卖；买卖请求股数为 `max(100, floor(1000 × confidence / 100) × 100)`，例如58%为500股、25%为200股、0%至不足10%为最低100股，HOLD始终不下单。置信度只是未校准的数量权重，不是盈利概率；最终成交仍受可卖库存、现金、盘口和区间成交量约束。未启用该参数的历史模式保留0.65置信度门槛。[上交所交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)规定交收前证券原则上不得卖出，允许当日回转的品种另有范围。

模型返回后加 1000 毫秒模拟延迟，只有整个累计成交量差额区间均晚于委托生效时间时才允许撮合。使用方向对应的买一或卖一价，按最小价位向不利方向舍入；每次可成交数量同时受盘口数量、真实区间成交量 10% 参与率、现金、昨仓、整手和涨跌停限制。挂单最多保留 10 秒，断档会撤销旧挂单。默认成本假设为滑点 1 基点、佣金万三且每单最低 5 元、卖出印花税万五、过户费十万分之一。这些参数是模拟假设，并未核对用户券商账单。

该方法无法复原队列、撤单、隐藏流动性或真实市场冲击，即使模拟成交也不能证明相同资金在实盘中可以成交。停止时不强制回补或虚构平仓；未回补库存单独展示并按当前价格计入权益。

## 收益和费用

页面同时展示当前总权益、原始底仓不动的基准权益及二者之差。闭合 T 净利润按相反方向成交配对，并分摊两边交易费用；降本金额为闭合净利润除以初始股数，不是实际历史成本变化。尚未配对的仓位必须与已闭合利润一同评估，不能单独展示盈利卖单而忽略待买回风险。

模型费用与交易账户盈亏分开展示。每次发请求前先保存费用预留额，收到供应商费用后只结算一次。供应商未返回费用或请求结果不确定时保留估计并标注，不显示为零费用，不自动重试付费请求。默认单次运行 300 秒、最多 120 次推理、费用上限 0.10 美元；代码允许的显式上限为 1800 秒、500 次和 10 美元。用户本轮明确批准单次上限10美元，运行时仍需显式传参；上限不代表会花完。不会修改供应商密钥月限额或自动充值。

## 持续运行与私有记录

当前连续账户保留800万元现值底仓、400万元现金与上述置信度配量规则。没有5分钟结束或推理次数限制；每秒检查新行情，周末及连续竞价时段外暂停取数和付费判断，开盘后重新积累量价窗口。当前未单独接交易所节假日日历，节假日仍由报价日期、源新鲜度和交易状态共同阻止付费判断与成交。模型费用按本账户与明确计入的先前费用累计，合计10美元耗尽即停止，不因关闭、重开或服务器重启而重置，不自动充值。

管理员开关为 `POST /api/v1/jev-live-t/control`，只接受严格布尔值 `enabled`，不能通过请求修改资金、权限或预算。`GET /control` 仅观察状态，其他账号不能控制或读取管理员账户。开关请求检查同源 Origin；前端防重复提交，无法确认结果时先读取状态而不自动重发开启操作。

服务保存联合账户与撮合引擎检查点，再生成只读页面投影。关闭后再开启使用同一run_id、现金、持仓、累计收益及费用；未完成挂单取消，不回放旧模型判断。异常中断时未确认的模型费用预留保留为估计，不把该请求重发。服务器正常退出保留用户的开启状态，下一次启动恢复；模型或持续行情故障会关闭并显示原因，需要人工重开。近期图表和明细保留有界窗口，累计账户、费用及收益不随明细压缩丢失，私有审计继续记录事件。

跨交易日仅在新的真实连续交易报价到达后，把前一日买入冻结股份转为昨仓；首条新日累计成交量只建基线，不伪造区间成交。没有券商账户、自动真实下单或资金划转。

### 单次有界研究命令

以下CLI仍供显式单次研究使用，不是网站持续开关的启动方式：

在项目根目录使用现有运行环境启动：

```sh
PYTHONPATH=. python scripts/run_jev_live_t.py \
  --symbol 603306.SH --owner admin \
  --base-value 8000000 --cash 4000000 \
  --duration 300 --max-requests 120 --max-cost-usd 10 --context market-news --confidence-sizing \
  --data-dir ./data/jev-live-t \
  --audit-file ./data/jev-live-t-audit/session-unique.jsonl
```

审计文件必须是新的文件名，避免覆盖已有证据。`--limits-file` 可提供已核验的 `date`、`limit_up` 和 `limit_down`，仅用于相同日期；跨日不复用。凭据通过既有专用钥匙串或 `JEV_RELAY_URL` 内存 relay 获取，不放在命令参数或记录里。

`JEV_LIVE_T_DIR` 指定服务端快照目录，未配置时为 `DATABASE_PATH` 同级的 `jev-live-t`。每次运行使用 UUID 文件，原子写入、文件权限 0600。审计与记录包含私有账户信息，不打包进公开静态产物或镜像。

运行记录的只读接口为 `GET /api/v1/jev-live-t/status`、`/runs` 和 `/runs/{run_id}`。复用已批准用户和管理员鉴权，不允许私有响应缓存；用户只能看 `user:<id>`，管理员试跑保存在 `admin` 命名空间。未知网站账号时保留管理员可见，不猜测、自动绑定或公开账户信息。

离线测试涵盖时间因果、T+1、累计量口径、限价及部分成交、费用、停止边界、进程超时、预算与所有者隔离。离线通过和历史回放都不等于实时运行，更不能证明收益提升；需另外记录当天真实试跑的时间、模型请求、成交与基准比较。本中文专题暂无对应英文页面。

部署约束：持续控制运行于当前单API进程，通过独占文件锁防止重复撮合循环；增加API进程数前需将开关状态协调扩展为跨进程协议。

## 秒级目标与实际频率

每秒检查新信息是调度目标，不等于每秒取得一条新行情或每秒发起推理。页面分别显示目标检查间隔、源时间实测更新间隔、最近模型HTTP响应、真实相邻请求间隔，以及最后请求/响应的上海时刻；缺少实际测量时显示未知，不借目标值补充。人工停止再恢复、午休与跨日后重新统计请求间隔，不把暂停时间当作请求性能。

2026-09-21实测现有新浪/腾讯华懋行情主要3秒快照，Mini数据库180条有174个3秒间隔和5个6秒间隔；配置中的Tushare令牌对实时rt_k接口返回40203权限不足。未接入授权逐笔通道前，不声称能产生每秒新增的交易所行情。快照的本地轮询加速、常驻模型worker或HTTP连接复用，都不能把3秒源数据变成真正1秒数据；离线连接/进程开销测试也不能代替生产模型时延测量。
