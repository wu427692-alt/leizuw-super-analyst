# Web 磨砂玻璃材质

沿用已批准的公开介绍首页，不改变业务页面的功能、数据或路由。公开手册与登录后的工作台共享冰白、浅蓝、淡桃的环境色和橙色操作强调；行情涨跌与状态的语义色保持原样。

## 覆盖与边界

- `UserGuideGlass.css` 为手册的独立材质层，兼容目录、搜索结果、章节、截图说明和预览；不重写手册内容与交互。手册保持明亮阅读模式。
- `GlassWorkspace.css` 为应用壳与已有业务面板提供统一材质；适配明暗主题。页面请求、后台任务、用户隔离和鉴权不属于本次修改范围。
- 外层玻璃面板使用轻薄边线、内侧高光与柔和阴影；表格、图表和长正文使用更实的阅读底，不能用透明度降低文字对比。
- 不把整页截图当作实际界面，也不使用设计概念图替代业务内容。手册内保留原有历史截图口径。

## 性能与可访问性

- 不增加数据请求、定时器、鼠标跟随或持续动画。
- 模糊只分配给有限外层／导航，不能给全部数据行或章节创建 GPU 模糊层。
- 手机减少透明叠层；保留可见焦点、原有滚动区域、原图比例和弹窗关闭行为。
- 提供不支持 `backdrop-filter` 与减少透明度偏好下的实色降级；既有减少动画偏好继续生效。

## 发布核验

- 从当前生产前端源码建立隔离基线，只合入本次材质文件及样式 import，不连带部署本地尚未验收的业务修改。
- 使用当前生产后端镜像叠加完整前端产物，保留旧哈希资源及回滚镜像。后端文件和数据卷不变。
- 发布后检查静态资源与容器入口哈希一致、公开首页仍是已批准版本、手册可公开阅读、业务路由仍需登录。
- 浏览器检查：手册检索与章节阅读、截图预览、桌面／手机、明暗主题及主要业务页面。样式验证不等于重新执行付费 AI、转写或交易研究任务。

本专题为中文 Web 产品样式说明，无对应英文专题；不改变英文配置和部署文档的操作语义。
